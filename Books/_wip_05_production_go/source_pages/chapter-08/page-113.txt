Benchmarking memory allocations
The Go benchmarking tools also allow us to output the number memory allocations by the
benchmark, alongside the time taken by each iteration. We do this by adding the -benchmem flag.
Let’s see what happens if we do this on our Fibonnaci benchmarks from before.
