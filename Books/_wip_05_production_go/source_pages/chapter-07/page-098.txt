Sometimes, when the existing code uses a specific library implementation, it takes refactoring to
use interfaces to mock out impementation details. However, the resulting code is more decoupled.
The tests run faster (e.g. when mocking out external network calls) and are more reliable. Don’t be
afraid to make liberal use of interfaces. This makes for more decoupled code and more focused tests.
