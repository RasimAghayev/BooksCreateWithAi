what should have happened. The onus is on you, the test author, to leave a helpful message for the
person debugging the code in the future. It is a good idea to assume that the person debugging your
failing test is not you, and is not your team. Make both the name of the test and the error message
relevant.

HTTP handler. First, let’s define a comically simple HTTP handler that writes a friendly response:
