One important note about struct field names and JSON: field names must be exported (first letter
of field name must be capitalized) in order for encoding to JSON to work. If our struct field names
were name and email, we would get an empty JSON object when marshalling.
Golang also supports anonymous structs, which can be commonly found in table-driven tests for
example. You can see some examples in our Testing chapter, but here is a quick (not testing-related)
example just to show how it works:

Operators
Operators in Go are very similar to other languages in the C-family. They can be divided into five
broad categories: arithmetic operators, comparison operators, logical operators, address operators
and the receive operator.
