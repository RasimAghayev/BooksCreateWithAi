Integers
The integer types can be divided into two classes, signed and unsigned.
Signed integers
The signed integer types are int8, int16, int32, int64, and int. Being signed, these types store both
negative and positive values, but up to a maximum half the value of its uint counterpart. int8 uses
8 bits to store values between -128 and 127 (inclusive). int16 stores values in the range -32,768 to
32,767. int32 stores values in the range -2,147,483,648 to 2,147,483,647. int64 stores values in the range
-2⁶³ to 2⁶³-1, which is to say, between -9,223,372,036,854,775,808 and 9,223,372,036,854,775,807.
