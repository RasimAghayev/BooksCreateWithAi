Error Handling
Error handling may take some getting used to when learning Go. In Go, your functions will normally
return whatever values you want to return, as well as an optional error value. To give a simple
example:

Note the multiple if err != nil checks. These are very common in idiomatic Go code, and
sometimes people who are new to Go have trouble adjusting to having to write them all the time.
You may see it as unnecessary code duplication. Why not have try/except like other languages?
We had similar thoughts when first starting out with Go, but eventually warmed up to the error
checking. When you’re that strict about returning and checking errors, it’s very hard to miss where
and why an error is happening.
