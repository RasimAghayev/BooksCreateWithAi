Channels
Channels can be used to send and receive values. They’re often used in goroutines; a goroutine will
do some work and then send the result to the channel that was passed in as an argument:

This code is functionally equivalent to our sync.WaitGroup example in the previous section. Note
that the channel must be declared before it’s used, as we see with ch := make(chan string). We create
the channel, then each goroutine sends a string onto the channel. Finally we select 3 values from the
channel and print them out at the end of the program.
