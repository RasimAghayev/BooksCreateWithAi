Refining Test with Mock Data
To make tests predictable and avoid potential flakiness, it's advisable to use
mock data. For our test, instead of fetching a book from a real database,
we'd fetch it from a mock datastore.
We shall assume we have a mock function:
func MockFetchBookByISBN(isbn string) (*Book, error) {
    return &Book{ISBN: "1234567890", Title: "Go in Action"}, nil
}
To use this mock function in tests, adjust the test function:
func TestFetchBookByISBN(t *testing.T) {
   book, err := MockFetchBookByISBN("1234567890")
    // rest of the test remains unchanged ...
}
Now, our test is independent of external data sources, making it more
robust.
