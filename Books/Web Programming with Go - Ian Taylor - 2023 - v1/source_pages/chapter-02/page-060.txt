Vendoring with Go Modules
When it comes to those who are inclined towards vendoring, even with Go
Modules in place, the process is straightforward. When you have finished
managing your dependencies, simply run:
go mod vendor
This populates the /vendor directory with the project's dependencies,
ensuring builds use these vendored packages.
Maintaining and Reviewing
Periodically, it's wise to review and update the dependencies. This not only
fetches updates with potential new features but also ensures security by
patching any vulnerabilities in the used packages.
Go's dependency management landscape has become more streamlined and
efficient, particularly since the introduction of modules. This is especially
true in that context. For the GitforGits Bookstore Web App, the focus
continues to be on ensuring consistency, reproducibility, and isolation. This
is true regardless of whether pure Go Modules are selected or whether the
app is integrated with vendoring.
