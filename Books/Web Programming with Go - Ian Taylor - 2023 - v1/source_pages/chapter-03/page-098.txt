registration, login, and profile access.
userRouter := r.PathPrefix("/users").Subrouter()
// User registration
userRouter.HandleFunc("/register", RegisterHandler)
// User login
userRouter.HandleFunc("/login", LoginHandler)
// View user profile
userRouter.HandleFunc("/profile", ProfileHandler)
Grouped under /users, these routes handle user-related functionalities,
ensuring a seamless user experience.
