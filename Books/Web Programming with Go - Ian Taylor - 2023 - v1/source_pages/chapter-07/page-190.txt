data sets.
Memory-Based Storage: One can store session data directly in
the application's memory. However, it's volatile; if the
application restarts, the data is lost.
File-Based Storage: This involves writing session data to files
on the server. It's more persistent than memory storage but can
become slow with a large number of concurrent sessions.
For example, using File-Based Storage:
// Using gorilla/sessions package
store := sessions.NewFilesystemStore("", []byte("secret-key"))
session, _ := store.Get(r, "session-name")
session.Values["user_id"] = "12345"
session.Save(r, w)
External Session Storage
Larger web apps prefer external storage solutions for scalability and
reliability. Databases (like PostgreSQL or MySQL) or caching systems (like
Redis) are popular choices.
For example using Redis:
// Using redistore
store, err := redistore.NewRediStore(10, "tcp", ":6379", "",
[]byte("secret-key"))
session, _ := store.Get(r, "session-name")
session.Values["user_id"] = "12345"
session.Save(r, w)
