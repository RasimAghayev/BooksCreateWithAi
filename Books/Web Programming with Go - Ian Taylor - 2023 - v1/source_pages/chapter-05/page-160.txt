Computes the sum of values. If GitforGits wanted to know the total stock
for a particular book:
SELECT SUM(stock) FROM inventory WHERE book_id =
some_book_id;
AVG
Calculates the average of values. To find the average book price:
SELECT AVG(price) FROM books;
MAX & MIN
Identify the highest and lowest value, respectively. To find the most and
least expensive book:
SELECT MAX(price), MIN(price) FROM books;
GROUP BY
Organizes rows sharing a property into summary rows. If GitforGits wished
to list the number of books by each author:
SELECT author_id, COUNT(*) FROM books GROUP BY
author_id;
HAVING
A filter applied after aggregation. To list authors who've written more than
five books:
SELECT author_id, COUNT(*)
FROM books
GROUP BY author_id
HAVING COUNT(*) > 5;
