The Create method accepts an order creation request from the client, converts it to
the Order domain model, and calls PlaceOrder via api dependency. As a final step, the
following code creates a listener socket and runs the gRPC server. This will also let the
consumer call the Create endpoint for order creation. You can simply add it to
server.go:
