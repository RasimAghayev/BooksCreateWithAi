Suppose you have multiple places like this where you call a dependent service from a con-
sumer service. Would you apply a circuit breaker pattern to all calls by wrapping them?
Or would you want some central place to manage the circuit breaker pattern? Let’s look
at how we can control circuit breaker logic in one place using gRPC interceptors.
 Remember, we already used UnaryClientInterceptor while handling a retry
operation for client-server communication. Now we will implement an interceptor
that allows us to pass circuit breaker logic as a parameter to ensure we return
UnaryClientInterceptor.

import (
    "context"
    "github.com/sony/gobreaker"
    "google.golang.org/grpc"
)
