5.2.3
Implementing the payment port
The payment port allows the Order service to call the Payment service
(http://mng.bz/V1xP). To define a basic contract in a payment port, you can simply
go to the Order service project we implemented in chapter 4 and create a payment
port file: mkdir -p internal/ports && touch internal/ports/payment.go.
 The payment port has only one functionality: charge. Simply pass the actual order
object, and it charges the customer based on order details:
package ports
import "github.com/huseyinbabal/microservices/order/internal/application/
➥ core/domain"
type PaymentPort interface {
    Charge(*domain.Order) error
}
