The fundamental goal of any software development team is to implement a set of
features in order to form a product and create direct or indirect business value.
This product can be distributed as a package that can be installed on a computer
offline or can be internet based and used online. Each programming language has
its own packaging methodology; for example, you can use a WAR or JAR file for
Java projects or a binary executable for Go projects. We call this monolithic architec-
ture: one or more features/modules are packaged as one product that completes
related tasks within a distributable object. When scalability problems arise, alterna-
