3.3.2
Automation for source code generation
GitHub Actions is a CI/CD platform that allows you to automate a building, testing,
and deployment pipeline. All the pipeline steps can be defined in the workflow file
that GitHub can detect under your repository’s .github/workflows folder. You don’t
need to be an expert on GitHub Actions to fully understand the examples, but, since
we are using GitHub Actions examples to explain CI/CD parts of this book, you may
want to look at the very short GitHub Actions Quickstart tutorial on Github:
https://docs.github.com/en/actions/quickstart.
