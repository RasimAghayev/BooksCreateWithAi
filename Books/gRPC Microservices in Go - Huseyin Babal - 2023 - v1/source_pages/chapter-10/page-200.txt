gRPC Microservices in Go teaches you how to build production-
ready microservices using Go and gRPC. In it, you’ll learn to 
create effi  cient APIs in Go, use gRPC for network communi-

to grasp each concept. You’ll also get an inside look at testing, 
deployment, and effi  cient DevOps practices for microservices.
