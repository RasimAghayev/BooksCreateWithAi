 We will illustrate this section with a function that returns a value and spins up a
goroutine that performs a job in the background. We will call a function to get a slice
of Foo structs and return the best element (the first one). In the meantime, the other
goroutine will be in charge of calling a Publish method with the first n Foo elements:
type Handler struct {
n
int
publisher publisher
}
type publisher interface {
Publish([]Foo)
}
func (h Handler) getBestFoo(someInputs int) Foo {
foos := getFoos(someInputs)
best := foos[0]
go func() {
if len(foos) > h.n {
foos = foos[:h.n]
}
h.publisher.Publish(foos)
}()
return best
}
The Handler struct contains two fields: an n field and a publisher dependency used
to publish the first n Foo structs. First we get a slice of Foo; but before returning the
first element, we spin up a new goroutine, filter the foos slice, and call Publish.
 How can we test this function? Writing the part to assert the response is straightfor-
ward. However, what if we also want to check what is passed to Publish?
