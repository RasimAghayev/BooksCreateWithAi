10.7.2 HTTP server
We should also be careful while implementing an HTTP server. Again, a default server
can be created using the zero value of http.Server:
server := &http.Server{}
server.Serve(listener)
Or we can use a function such as http.Serve, http.ListenAndServe, or http
.ListenAndServeTLS that also relies on the default http.Server.
 Once a connection is accepted, an HTTP response is divided into five steps:
1
Wait for the client to send the request.
2
TLS handshake (if enabled).
3
Read the request headers.
4
Read the request body.
5
Write the response.
NOTE
The TLS handshake doesn’t have to be repeated with an already estab-
lished connection.
Figure 10.3 shows how these steps relate to the main server timeouts. The three main
timeouts are the following:

http.Server.ReadHeaderTimeout—A field that specifies the maximum
amount of time to read the request headers

http.Server.ReadTimeout—A field that specifies the maximum amount of
time to read the entire request

http.TimeoutHandler—A wrapper function that specifies the maximum
amount of time for a handler to complete
