 To improve how fast an address can be accessed from a CPU cache, designers work
on different policies regarding cache placement. Let’s skip the history and discuss
today’s most widely used option: set-associative cache, which relies on cache partitioning.

during the iteration.
Each memory block contains 64 bytes and hence 8 int64 elements. The first memory
block starts at 0x0000000000000, the second begins at 0001000000000 (512 in
binary), and so on. We also show the cache that can hold 8 lines.
