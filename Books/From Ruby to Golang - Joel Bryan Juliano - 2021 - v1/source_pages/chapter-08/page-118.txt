Glossary
\N
a Control Character Sequence Signifying
a Newline
!
The Logical NOT Operator, can be
Applied to a Boolean Which Converts
the Operand Into it’s Anti Equivalent
Value, and Will Return False Values for
Non-boolean.
""
An Empty String, if the String is a Type,
Enclose the String in Between Quotes
Specifying a String
#<Set: {"Apple", "Broccoli"}>
the Printed Value of a Ruby set in it’s
Object Form Containing two Items
$
The Dollar Sign, in Shell Scripts, it is a
Special Character That Preceded With a
Name Containing a Stored Value
$GOPATH
the Library Lookup Path for go Programs
Using old Module System, This Form it
is Being Executed in a Shell Script or
Terminal
%+v
a Special fmt Printing Construct That
Prints the Value and Field Names of a
Struct.
%s
a Special fmt Printing Construct That
Prints the Value as a String Type
%
The Percent Sign, in go, it is a Special
Character That Preceded With a Type
Signifying an Expected Return Value
Passed as Parameters
&&
A Logical AND Operator
&MapName{}
a go map Without any Values Initialized.
can be Readily Assigned to a Value Like
a Normal Variable
