Hash and Maps
If you need to store amounts of data programmatically in Go, that you can conveniently retrieve by
its name and not by its index, then use a map. A map is storage of records that allows retrieval using
a key mapping to a value. It is a good way to organize information for easy retrieval.
A key/value store database (i.e. Redis, Amazon DynamoDB, Riak, Tokyo/Kyoto Cabinet)
works the same concept as a map.
Coming from Ruby, a map’s equivalent is a hash. Hashes can be implicitly created using {} or
idiomatically through Hash.new. Here’s how to create a hash in Ruby. First, we initialize an empty
hash by assigning {} to a variable named basket, then we iterate the contents and print the key
name and its value.
Hash
1
basket = {}
2
basket[:fruits] = %w[apple mango avocado]
3
basket[:veggies] = %w[carrot cucumber kale]
4
5
basket.each do |key, val|
6
puts "Key #{key} -- Value #{val.join(' ')}"
7
end

$ ruby basket.rb

Key veggies -- Value carrot cucumber kale
In order for us to replicate this example in Go, we would use Go’s built-in keyword called map and
place it into a variable that maps a unique name to a value. But before we proceed on creating a map,
we would need to understand two ways to initialize and allocate a map.
- Map by declaration, being able to initialize and allocate later.
- Map by assignment, a one-liner way to initialize and allocate a
map.
