In the following example, we created a basket function accepting a variadic function ... to
map[string]interface{} so that we can pass multiple arguments to the function. Then we pass
a map and a string as an argument to the basket function, then we access the map’s values using
item["name"], item["flavour"] and kind.

Noticed that on line 15, we have an expression .(map[string]string) to the first argument, this is
because the variadic ...interface{} will act as an array container of the arguments you pass into
it and to access the argument, it needs to be type asserted back to map[string]string.
