Router implementation
considerations
If you perform a search for Go Frameworks, you will come across a variety of
different solutions, all with slightly different routing implementations. Luckily,
based on https://github.com/julienschmidt/go-http-routing-benchmark, we have a
mechanism by which we can pit all of these routers against each other to see
which performs the best and which performs the worst under certain situations.
Using these benchmarks when I was initially investigating router capabilities,
the benchmarks provided gave some excellent insight into the efficiencies of the
various routers from 2015:

It is pretty clear that in my initial testing of the various web application
frameworks, the Gin and Echo frameworks were the best performers with large
API definitions. Echo was able to resolve a route within its router
implementation within 38,662 nanoseconds on average, which is incredibly fast.
