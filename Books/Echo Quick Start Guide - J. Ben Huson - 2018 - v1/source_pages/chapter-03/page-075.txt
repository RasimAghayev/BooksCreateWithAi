How Echo routing works
As mentioned previously, Echo employs a Radix Tree data structure and search
algorithm to find the correct handler for a given resource identifier. A Radix Tree
is a prefix tree, where each parent node in the tree represents a prefix of the child
node. In our use case, since we are obviously performing string matching, a
prefix tree is the appropriate tool for the job. The following is an extremely
simplified diagram that explains how a Radix Tree works for our book-long
project:
The preceding diagram assumes the following routes were added to our project,
which can be seen in our sample code located at:
$GOPATH/src/github.com/PacktPublishing/Echo-Essentials/chapter3/cmd/service/main.go:
// in order to serve static assets
    e.Static("/static", "static")
    // reminder handler group
    reminderGroup := e.Group("/reminder")
    reminderGroup.Use(middleware.JWT(signingKey))
    reminderGroup.POST("", handlers.CreateReminder)
    // Route / to handler function
    e.GET("/health-check", handlers.HealthCheck)
    // Authentication routes
    e.POST("/login", handlers.Login)
    e.POST("/logout", handlers.Logout)
