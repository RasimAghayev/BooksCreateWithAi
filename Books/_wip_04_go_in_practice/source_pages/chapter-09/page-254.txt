If you want to compile to multiple operating systems and architectures, one option is
gox, which enables building multiple binaries concurrently, as shown in figure 9.4. 
You can install gox as follows:
$ go get -u github.com/mitchellh/gox
After gox is installed, you can create binaries in parallel by using the gox command.
The following listing provides an example of building an application for OS X, Win-
dows, and Linux on both the AMD64 and 386 architectures.
$ gox \
  -os="linux darwin windows " \
  -arch="amd64 386" \
  -output="dist/{{.OS}}-{{.Arch}}/{{.Dir}}" .
When building binaries in other operating systems—especially when operating them
in the cloud—it’s a best practice to test the result before deploying. This way, any envi-
ronment bugs can be detected before deploying to that environment.
