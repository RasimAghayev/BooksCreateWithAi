TECHNIQUE 30
Parallel benchmarks
One of Go’s strongest points is its goroutine model of concurrent programming. But
for any given piece of code, how can you tell how well it will perform when spread out
over multiple goroutines? Again, the benchmarking tool can help you here.
PROBLEM
You want to test how a given piece of code performs when spread over goroutines. Ide-
ally, you want to test this with a variable number of CPUs.
SOLUTION
A *testing.B instance provides a RunParallel method for exactly this purpose. Com-
bined with command-line flags, you can test how well goroutines parallelize.
DISCUSSION
Beginning with listing 5.21, you can fashion the template test into a parallel test.
