From this file, we can navigate to the results using go tool:
$ go tool pprof -http=:8080 <file>
This command opens a web UI showing the call graph. Figure 12.34 shows an exam-
ple taken from an application. The larger the arrow, the more it was a hot path. We
can then navigate into this graph and get execution insights.

CPU profiling during benchmarks
We can also enable the CPU profiler using the -cpuprofile flag, such as when run-
ning a benchmark:
$ go test -bench=. -cpuprofile profile.out
This command produces the same type of file that can be downloaded via /debug/
pprof/profile.
