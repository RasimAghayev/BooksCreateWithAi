# Terminologiya

Bu kitabda işlənən əsas texniki terminlər və onların Azərbaycanca
qarşılıqları.

## A

- **ACID** (Atomicity, Consistency, Isolation, Durability / Atomalıq,
  Ardıcıllıq, İzolyasiya, Davamlılıq) — Verilənlər bazası tranzaksiyalarının
  təhlükəsizliyini təmin edən 4 prinsip.
- **API** (Application Programming Interface / Tətbiq Proqramlaşdırma
  Interfeysi) — Proqramlar arasında əlaqə üçün interfeys.
- **ArgoCD** — Kubernetes üçün declarative GitOps continuous delivery
  (davamlı çatdırılma) aləti.

## C

- **Channel (Kanal)** — Goroutine-lər arasında data exchange üçün
  istifadə olunan Go konstruksiyası.
- **CI/CD** (Continuous Integration / Continuous Deployment / Davamlı
  İnteqrasiya / Davamlı Yerləşdirmə) — Kodun avtomatik testlənməsi və
  productiona çatdırılması prosesi.
- **Clean Architecture** — Təmiz arxitektura, məsuliyyətlərin ayrılması
  prinsipi.
- **Composition (Tərkib)** — OOP inheritance əvəzinə obyektlərin
  tərkibindəki sahələr vasitəsilə yenidən istifadə.
- **Compilation (Kompilyasiya)** — Mənbə kodunu maşın koduna
  çevirmək prosesi.
- **Concurrency (Paralellik)** — Eyni anda bir neçə prosesin icrası.
- **Containerization (Konteynerləşdirmə)** — Tətbiqi və onun
  asılılıqlarını konteynerə qablaşdırmaq.

## D

- **Dependency Injection (Asılılıqların inyeksiyası)** — Asılılıqların
  xaricindən təmin edilməsi prinsipi.
- **Docker** — Konteynerləşdirmə platforması.
- **Docker Compose** — Çoxkonteynerli tətbiqlərin təsviri və idarəsi
  üçün alət.
- **Domain-Key Normal Form (DKNF / Dömən-Açar Normal Forması)** —
  Verilənlər bazasının ən yüksək normal forması.

## G

- **Generics (Cəmiçi tiplər)** — Tip parametrləri ilə funksiyalar və
  strukturlar yaratmaq imkanı.
- **Git** — Distribütiv versiya idarəsi sistemi.
- **Golang (Go)** — Google tərəfindən yaradılmış proqramlaşdırma dili.
- **GOPATH** — Go layihələri üçün köhnə iş qovluğu dəyişəni.
- **Goroutine (Qorutin)** — Go dilinin yüngül icra növü.
- **GORM** — Go üçün ORM (Object-Relational Mapping) kitabxanası.
- **Go Modules** — Go 1.11+ ilə gələn asılılıqların idarə edilməsi
  sistemi.
- **GVM (Go Version Manager)** — Bir neçə Go versiyasını idarə etmək
  üçün alət.

## H

- **HTTP** (HyperText Transfer Protocol / HyperText Transfer Protokolu) —
  Veb üçün əsas protokol.

## I

- **Idempotency (Idempotenslik / Təkrar emsallıq)** — Əməliyyatın
  bir neçə dəfə təkrar edilməsinin eyni nəticə verməsi xüsusiyyəti.
- **IntelliSense** — Kod avtomatik tamamlama və xəta aşkarlama
  xüsusiyyəti.
- **Isolation Level (İzolyasiya səviyyəsi)** — Verilənlər bazası
  tranzaksiyalarının bir-birini necə görə biləcəyini müəyyən edən səviyyə.

## J

- **JWT** (JSON Web Token) — JSON əsasında token, autentifikasiya və
  avtorizasiya üçün.

## K

- **Kafka** — Distributed streaming platform, hadisə əsaslı arxitektura
  üçün.
- **Kubernetes (K8s)** — Konteyner orkestrasiya platforması.

## M

- **Message Broker (Mesaj brokeri)** — Servislər arasında mesaj
  mübadiləsini idarə edən sistem.
- **Microservice (Mikroservis)** — Kiçik, müstəqil, müəyyən funksiyanı
  yerinə yetirən xidmət.
- **Migration (Miqrasiya)** — Verilənlər bazası strukturu dəyişikliklərini
  idarə etmək mexanizmi.
- **Monolith (Monolit)** — Bütün funksionallığı tək proses kimi
  işləyən arxitektura.

## O

- **ORM** (Object-Relational Mapping / Obyekt-Əlaqəli Xəritələmə) —
  Obyekt yönümlü dillərdə verilənlər bazası ilə işləməyi asanlaşdıran
  kitabxana.

## P

- **Pod** — Kubernetes-ın ən kiçik deployable (yerləşdirilə bilən) vahidi.
- **PostgreSQL** — Açıq mənbəli obyekt-relational verilənlər bazası
  sistemi.
- **Production (İstehsal mühiti)** — Fərdi istifadəçilər üçün aktiv
  sistem.
- **Protobuf** (Protocol Buffers) — Serializasiya formatı, əsasən RPC
  üçün.

## R

- **Race Condition (Yarış vəziyyəti)** — Eyni anda eyni resursa müraciət
  edən iki və ya daha çox proses arasında yaranan problem.
- **Redis** — In-memory data structure store, cache və pub/sub üçün.
- **Refactoring (Refaktorinq)** — Kodun daxili strukturunu dəyişmədən
  davranışını yaxşılaşdırmaq.
- **REST** (Representational State Transfer) — Arxitektura tərzi,
  HTTP protokolundan istifadə edərək resurslar üzərində əməliyyatlar.

## S

- **Saga** — Paylanmış tranzaksiyaları idarə etmək üçün kompensasiya
  pattern-i.
- **SaaS** (Software-as-a-Service / Proqram kimi Xidmət) — Bulud əsaslı
  tətbiq modeli.
- **Supply Chain Attack (Zəncirlə Təchizat Hücumu)** — Tərəfi
  asılılıqlara zərərli kod əlavə etmək hücumu.
- **Swagger** — REST API-ləri documentasiya etmək üçün alət.

## T

- **Two-Phase Commit (2PC / İki Mərhəmətli Fiqaslama)** — Paylanmış
  tranzaksiyaları koordinasiya etmək mexanizmi.
- **Throughput (Ötürmə qabiliyyəti)** — Sistemin müəyyən vaxt
  intervalında emal edə biləcəyi iş həcmi.

## V

- **Vault** — Məxfi məlumatları (şifrələr, sertifikatlar) saxlamaq və
  idarə etmək aləti.
- **Vulnerability (Zəiflik)** — Sistemin təhlükəsizlik poziçiyasında
  olan açıq.

## W

- **Web Server (Veb server)** — HTTP protokolundan istifadə edərək
  tətbiqi istifadəçilərə təqdim edən proqram.
