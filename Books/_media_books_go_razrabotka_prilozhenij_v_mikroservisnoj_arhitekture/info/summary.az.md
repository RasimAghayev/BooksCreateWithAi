# Go: разработка приложений в микросервисной архитектуре с нуля — Kitab xülasəsi

## Kitab nə haqqındadır?
Bu kitab Go dili ilə mikroservis əsaslı tətbiqlərin hazırlanmasını
praktiki nümunələrlə izah edir. Kiçik bir mikroservisdən başlayaraq,
müxtəlif texnologiyalar tətbiq edən mikroservis qrupuna və virtual
serverlərə yerləşdirilmiş hazır tətbiqə qədər davam edir.

## Əsas texnologiyalar
- **Go (Golang):** Başlıc proqramlaşdırma dili, kompilyasiya edilən,
  yüksək performanslı, server development üçün nəzərdə tutulmuşdur.
- **PostgreSQL:** Obyekt-relational verilənlər bazası, data persistence
  (data persistence / məlumatların davamlılığı) üçün istifadə olunur.
- **Docker & Docker Compose:** Konteynerləşdirmə və çoxkonteynerli
  tətbiqlərin idarə edilməsi.
- **Kubernetes:** Konteyner orkestrasiya platforması, miqyaslama və
  yerləşdirmə üçün.
- **gRPC:** Yüksək performanslı RPC framework, servislərarası
  kommunikasiya üçün.
- **Apache Kafka:** Distributed streaming platform, hadisə əsaslı
  arxitektura üçün.
- **Redis:** In-memory data structure store, cache və pub/sub üçün.

## Əsas mövzular
1. **Mikroservis arxitekturası:** Modullara ayrılma, kommunikasiya,
   data consistency.
2. **Go dili:** Goroutines, channels, minimal sintaksis, güclü
   standard library.
3. **Verilənlər bazası:** PostgreSQL, ORM (GORM), normal formalar,
   migrasiyalar.
4. **API dizaynı:** REST, Swagger, validasiya.
5. **Təhlükəsizlik:** Authentication, Authorization, JWT, RBAC,
   vulnerability prevention.
6. **Kommunikasiya:** HTTP, gRPC, message broker-lər (RabbitMQ,
   Kafka, Redis).
7. **Paylanmış tranzaksiyalar:** ACID, 2PC, Saga pattern,
   idempotency.
8. **Konteynerləşdirmə:** Docker, Docker Compose, multi-stage build.
9. **Orkestrasiya:** Kubernetes, Pod, Deployment, Service, Ingress,
   HPA.
