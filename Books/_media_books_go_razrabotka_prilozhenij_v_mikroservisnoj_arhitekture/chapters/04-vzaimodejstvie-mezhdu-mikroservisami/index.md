# Chapter 3 — Способы взаимодействия между микросервисами

Pages: 111-156

## Bu chapter nədən bəhs edir?
Bu chapter mikroservislərin bir-biri ilə necə əlaqə saxlamasını,
kommunikasiya modellərini, mesaj brokerləri və API Gateway-ni izah edir.

## Əsas fikirlər
### 1. Kommunikasiya modelləri
- Synchronous communication (sinxron kommunikasiya) — HTTP, gRPC
- Asynchronous communication (asinxron kommunikasiya) — message brokers

### 2. Protokollar
- HTTP/HTTPS — tətbiq səviyyəli protokol
- gRPC — yüksək performanslı RPC framework
- OSI modeli və TCP/IP

### 3. Message Broker-lər
- RabbitMQ — yüngül mesaj brokeri
- Apache Kafka — yüksək throughput-lu streaming platforma
- Redis — in-memory data structure store, pub/sub

### 4. API Gateway
- Təkmilləşdirilmiş Gateway arxitekturası
- Routing, load balancing, rate limiting

## Əsas terminlər
- Microservice Communication (mikroservis kommunikasiyası)
- HTTP (HyperText Transfer Protocol)
- gRPC (Google Remote Procedure Call)
- REST (Representational State Transfer)
- Message Broker (mesaj brokeri)
- RabbitMQ (açıq mənbəli mesaj brokeri)
- Apache Kafka (distributed streaming platform)
- Redis (in-memory data structure store)
- API Gateway (API şəbəkə qapısı)
- Load Balancer (yük bərabərləndirici)
- Latency (gecikmə)
- Throughput (ötürmə qabiliyyəti)

## Praktik nəticə
Bu chapter-də Gateway mikroservisi hazırlanır və müxtəlif kommunikasiya
modelləri praktikada tətbiq olunur.
