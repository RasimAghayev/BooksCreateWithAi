# Chapter 1 — Cheat Sheet

## Go komandaları

### `go version`
**Nə edir:** Quraşdırılmış Go versiyasını göstərir.

**Mənbə:** Chapter 1, page 14

### `go get`
**Nə edir:** Yeni asılılığı endirir və əlavə edir.

**Mənbə:** Chapter 1, page 17

### `go build`
**Nə edir:** Layihəni kompilyasiya edir.

**Mənbə:** Chapter 1, page 17

### `go test`
**Nə edir:** Testləri icra edir.

**Mənbə:** Chapter 1, page 17

## GVM komandaları

### `gvm list`
**Nə edir:** Quraşdırılmış Go versiyalarının siyahısını göstərir.

**Mənbə:** Chapter 1, page 18

## Godep komandaları

### `godep restore`
**Nə edir:** Godeps/Godeps.json faylında göstərilən bütün asılılıqları
$GOPATH-a quraşdırır.

**Mənbə:** Chapter 1, page 16

## Glide komandaları

### `glide init`
**Nə edir:** Yeni layihə üçün glide.yaml faylı yaradır.

**Mənbə:** Chapter 1, page 16

### `glide install`
**Nə edir:** glide.lock faylında göstərilən versiyaları quraşdırır.

**Mənbə:** Chapter 1, page 16

### `glide update`
**Nə edir:** Asılılıqların versiyalarını yeniləyir.

**Mənbə:** Chapter 1, page 16

## GVM quraşdırma

### `bash < <(curl -s -S -L https://raw.githubusercontent.com/moovweb/gvm/master/binscripts/gvm-installer)`
**Nə edir:** GVM quraşdırma skriptini endirir və icra edir.

**Mənbə:** Chapter 1, page 18

### `source ~/.bashrc`
**Nə edir:** Hal-hazırki terminal sessiyasını yeniləyir, GVM dəyişənlərini
yükləyir.

**Mənbə:** Chapter 1, page 18
