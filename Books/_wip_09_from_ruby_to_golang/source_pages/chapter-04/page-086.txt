Questions
1. What have we learned?
We can use the index semantic form for a range to skip the value parameter of the for loop
(the 2nd parameter) and initialize it directly to get the array index.
2. Why is this important to iterate an index?
This is important because it allows us to write more concise code.
3. How is index in for-loop iteration used?
It is used to access the value at that index.
Value Semantic Form with Pointer Access
We can also access the pointer to its memory address directly, but directly accessing the memory
pointer is a bad practice, especially when we are doing mutations to the same pointer.
