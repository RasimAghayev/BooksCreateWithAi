You can only access the value by calling the literal name of the type in the struct, and with this
semantics, it comes with a limitation.
It is important to take note that when using anonymous field names, you have a limitation of having
a declaration of the same type only once, since anonymous struct fields need to have unique value
types, otherwise, there cannot be a distinction between each type.
