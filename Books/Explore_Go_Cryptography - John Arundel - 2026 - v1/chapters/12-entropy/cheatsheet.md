# Cheat Sheet — Entropy

## Entropiya Hesablanması

### Şannon Entropiyası
```
H(X) = -Σ p(x) log₂ p(x)
```
- `p(x)` — Hər simvolun müşahidə edilmə ehtimalı
- `H(X)` — Məlumatın entropiyası (bitlərlə)

**Nümunə:** 16 simvol və eyni ehtimallı parol üçün:
```
H = log₂(16) = 4 bits
```
