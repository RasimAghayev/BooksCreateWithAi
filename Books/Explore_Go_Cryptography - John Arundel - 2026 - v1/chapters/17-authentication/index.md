# 17. Authentication

**Səhifələr:** 278-294

## Bu fəsil nədən bəhs edir?

Mesaj autentifikasiyası (MAC, HMAC), autentifikasiya olunmuş şifrələmə (AEAD) və açar mübadiləsi protokolları.

## Əsas fikirlər

### 1. Message Authentication Code (MAC)
Mesajın dəyişdirilməməsi və mənbəyinin doğrulanması üçün hash funksiyası və açar istifadə edən mexanizm.

### 2. AEAD (Authenticated Encryption with Associated Data)
Şifrələmə və autentifikasiyanı eyni anda təmin edən rejim (məsələn, AES-GCM).

### 3. Key Exchange (Açar Mübadiləsi)
İki tərəf arasında təhlükəsiz şəkildə açar ötürmək protokolları.

## Əsas terminlər
- MAC (Message Authentication Code)
- HMAC (Hash-based MAC)
- AEAD (Autentifikasiya olunmuş şifrələmə)
- Key Exchange (Açar mübadiləsi)
- Nonce (Yanlız bir dəfə istifadə edilən dəyər)

## Praktik nəticə

HMAC və AEAD testləri yazılır. Real dünya tətbiqləri nümayiş etdirilir.
