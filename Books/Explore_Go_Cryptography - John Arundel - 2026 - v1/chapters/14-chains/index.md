# 14. Chains

**Səhifələr:** 226-247

## Bu fəsil nədən bəhs edir?

Hash chain-ləri və Merkle ağacları (Merkle trees). Məlumat bütövlüyünü yoxlamaq və blokçeyn protokolları üçün əsas struktur.

## Əsas fikirlər

### 1. Hash Chain
Hər hash dəyəri əvvəlki hash ilə əlaqələndirilir. Dəyişiklik aşkar edilməsi üçün effektivdir.

### 2. Merkle Tree
Ağac strukturunda hash-lərin dəstəklənməsi. Tək bir root hash ilə böyük məlumat dəstinin bütövlüyünü yoxlamaq mümkündür.

### 3. Blockchains
Merkle ağacları blokçeyn protokollarının (məsələn, Bitcoin) əsasını təşkil edir.

## Əsas terminlər
- Hash Chain (Hash zənciri)
- Merkle Tree (Merkle ağacı)
- Root Hash (Kök hash)
- Blockchain (Blokçeyn)
- Data Integrity (Məlumat bütövlüyü)

## Praktik nəticə

Go-da Merkle ağacı implementasiyası. Hash chain mexanizmi izah edilir.
