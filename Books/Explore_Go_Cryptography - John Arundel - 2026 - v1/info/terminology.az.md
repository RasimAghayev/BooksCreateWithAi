# Terminology — Explore Go: Cryptography

Bu fayl kitabda rast gəlinən əsas texniki terminləri və onların Azərbaycanca qarşılıqlarını ehtiva edir.

## A

- AES (Advanced Encryption Standard) — Təkmil Şifrələmə Standartı
- Authentication (Autentifikasiya) — Kimlik təsdiqi
- Authenticated Encryption (Autentifikasiya olunmuş şifrələmə) — Şifrələmə və bütövlük yoxlaması

## B

- Block Cipher (Blok şifrəsi) — Sabit ölçülü bloklar üzərində işləyən şifrə
- Brute Force Attack (Zorla hücum) — Bütün mümkün açarları sınaqdan keçirmək
- Byte (Bayt) — 8 bitlik məlumat vahidi

## C

- CBC (Cipher Block Chaining) — Şifrə blokları zənciri
- Cipher (Şifrə) — Məlumat gizlədilməsi alqoritmi
- Code (Kod) — Alternativ mesaj təmsili
- Commitment Scheme (İmdatlaşdırma sxemi) — Dəyəri gizləyib sonradan açmaq
- Cracker (Kırıcı) — Şifrəni kırmaqla məşğul olan şəxs
- Cryptanalysis (Kriptanaliz) — Şifrələri kırmaq sənəti
- Cryptocurrency (Rəqəmsal pul) — Kriptoqrafik protokollərlə idarə olunan pul
- Cryptography (Kriptografiya) — Gizli yazı sənəti

## D

- Decryption (Şifrəni açma) — Şifrələnmiş məlumatı orijinal formasına qaytarmaq
- Digest (Hesaslama) — Hash funksiyasının çıxardığı sabit ölçülü dəyər

## E

- ECB (Electronic Codebook) — Elektron kod kitabçası rejimi
- Encryption (Şifrələmə) — Məlumatı gizlətmək
- Entropy (Entropiya) — Məlumatın qeyri-müəyyənlik dərəcəsi
- Enumeration (Sıralama) — Açar məkanını sistematik yoxlamaq

## G

- GCM (Galois/Counter Mode) — Qalois/Countre rejimi
- Goroutine — Go dilinin eyni anda işləyən funksiyası

## H

- HMAC (Hash-based Message Authentication Code) — Hash əsaslı mesaj autentifikasiya kodu
- Hash Function (Hash funksiyası) — Məlumatı sabit ölçülü dəyərə çevirən funksiya
- Hashing (Hesaslama) — Hash dəyəri çıxarmaq prosesi

## I

- IV (Initialization Vector) — Başlanğıc vektoru

## K

- Key (Açar) — Şifrələmə/deşifrələmə üçün gizli məlumat
- Keyspace (Açar məkanı) — Mümkün açar dəyərlərinin sayı
- Key Stretching (Açar uzatma) — Şifrəni təhlükəsiz açar halına çevirmək
- KDF (Key Derivation Function) — Açar çıxarma funksiyası

## M

- MAC (Message Authentication Code) — Mesaj autentifikasiya kodu
- Merkle Tree (Merkle ağacı) — Hash ağacı strukturu
- Mode of Operation (İşləmə rejimi) — Blok şifrələrinin emal rejimi
- Multi-byte Key (Çox baytlı açar) — Bir neçə baytdan ibarət açar

## N

- Nonce (Yanlız bir dəfə istifadə edilən dəyər) — Təkrar istifadə edilməyən təsadüfi rəqəm
- NIST (National Institute of Standards and Technology) — ABŞ standartları institutu

## P

- Padding (Doldurma) — Blok tam olmadıqda əlavə baytlar
- PBKDF2 — Şifrə əsaslı açar çıxarma funksiyası
- Plaintext (Açıq mətn) — Şifrələnməmiş məlumat
- PRNG (Pseudorandom Number Generator) — Təxmin edilən təsadüfi rəqəm generatoru
- Pseudorandom (Təxmini təsadüfi) — Həqiqi təsadüfi deyil, sadəcə təsadüfi kimi görünən

## R

- Randomness (Təsadüfiyyət) — Təxmin edilə bilməyənlik
- RSA — Rivest-Shamir-Adleman kriptoqrafik alqoritmi

## S

- Salt (Duz) — Eyni şifrə ilə eyni hash alınmasının qarşısı üçün əlavə məlumat
- Score (Skor) — Açarın düzgünlüyünü təxmin edən dəyər
- SHA-256 — 256-bitlik hash funksiyası
- Shift Cipher (Sürüşmə şifrəsi) — Hərfləri müəyyən sayda dəyişdirən şifrə
- Stream Cipher (Axın şifrəsi) — Bit/bit və ya bayt/bayt emal edən şifrə
- Subtests (Alt testlər) — `t.Run` ilə yaradılan kiçik testlər

## T

- TDD (Test-Driven Development) — Test əsaslı inkişaf
- Test Case (Test zamanı) — Test üçün nümunə məlumatlar

## Z

- Zero-Knowledge Proof (Sıfır bilik sübutu) — Məlumatı açıqvermədən doğruluğunu sübut etmək
