# Learn Go with Pocket-Sized Projects

**Müəlliflər:** Aliénor Latour, Donia Chaiehloudj, Pascal Bertrand (Manning, 2023)
**Səviyyə:** L2 Elementary · **Dil:** Go · 782 səhifə · 12 chapter + appendix

layihədir — CLI alətləri, kitabxana, HTTP service, concurrent maze solver, gRPC
backend + HTML frontend, Wasm/TinyGo.
