# 0. Preface

**Səhifələr:** 1-29

## Bu fəsil nədən bəhs edir?

Kitabın ön sözü və giriş hissəsi. Müəllifin React 18, müasir web development və bu kitabın kim üçün nəzərdə tutulduğu haqqında ümumi baxışı.

## Əsas fikirlər

### 1. React-in qısa tarixi və Meta-nın rolu

React 2013-cü ildə Meta (o zamankı Facebook) tərəfindən open-source olaraq yayımlandı. Bu gün yüzlərlə contributor və milyonlarla developer tərəfindən istifadə olunur. Bu bölmədə React-in populyarlığının səbəbləri izah edilir: sürətli DOM idarəsi, JSX-in gücü, server-side rendering imkanları.

### 2. Kitabın kim üçün olduğu

Bu kitab web developer-lər üçündür. Orta səviyyəli React və JavaScript biliyi tələb olunur. Əgər React ilə kiçik/orta layihə qurmusan və biliklərini dərinləşdirmək istəyirsənsə, bu kitab sənin üçündür.

### 3. Kitabda əhatə olunan mövzular

Kitab 17 əsas fəsil + əlavə fəsildən ibarətdir: React fundamentals, TypeScript, JSX, Composition Patterns, Forms/Events, Styling, Anti-patterns, Hooks, Routing, React 18 new features, Data management, SSR, GraphQL, MonoRepo, Performance, Testing, Deployment.

### 4. Öyrənmək üçün tələblər

Node.js-in son versiyasını quraşdırmağı bacarmaq, JavaScript ES6 sintaksisini bilmək, CLI alətləri ilə işləmək təcrübəsi tələb olunur.
