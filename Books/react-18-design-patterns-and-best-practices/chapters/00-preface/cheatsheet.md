# Cheat Sheet — Preface

## Kitab strukturu

### Vite ilə React layihəsi yaratmaq

**Nə edir:** `react-ts` şablonu React + TypeScript layihəsi yaradır.

**Kod:**

```shell
npm create vite@latest my-app -- --template react-ts
```

**Mənbə:** Chapter 0, page 1-29

### Vite dev server

**Nə edir:** Development server port 5173-də işə düşür, hot reload aktiv olur.

**Kod:**

```shell
npm run dev
```

**Mənbə:** Chapter 0, page 1-29

### Layihə strukturunu anlamaq

**Nə edir:** Vite standart strukturu: `src/` daxilində komponentlər, `index.html` entry point, `vite.config.ts` build konfiqurasiyası.

**Kod:**

```shell
src/, public/, index.html, vite.config.ts, tsconfig.json
```

**Mənbə:** Chapter 0, page 1-29
