# 18. Other Books You May Enjoy and Index

**Səhifələr:** 501-525

## Bu fəsil nədən bəhs edir?

Bu fəsil Packt Publishing-in digər React və JavaScript kitablarını tövsiyə edir və mövzu indeksini ehtiva edir.

## Əsas fikirlər

### 1. Tövsiyə olunan kitablar

Packt React kitabları seriyasından digər nəşrlər (React Cookbook, React Projects, React Native kitabları və s.). Hər birinin qısa təsviri verilir ki, oxucu əlavə öyrənmə üçün seçim edə bilsin.

### 2. Mövzu indeksi

Kitabda rast gəlinən bütün əsas termin və anlayışların əlifba sırası ilə indeksi. Bu, konkret mövzuya tez müraciət etmək üçün faydalıdır.

### 3. Davamlı öyrənmə

React ekosistemi sürətlə inkişaf edir. React Server Components, Next.js App Router, Server Actions kimi yeni texnologiyalar daimi öyrənməyi tələb edir. Rəsmi React sənədləri (react.dev) həmişə ən etibarlı mənbədir.
