## Kitab haqqında

"React 18 Design Patterns and Best Practices" dördüncü nəşri React ekosisteminin ən son vəziyyətini əhatə edir. Kitab React-in əsaslarından başlayaraq müasir patternlər, Hooks, GraphQL, MonoRepo arxitekturası və production deploymentə qədər geniş bir yol təqdim edir.

## Əsas fəaliyyət sahələri

1. **React-in əsasları:** Declarative vs imperative yanaşma, React elements, JSX, komponent məntiqi.
2. **TypeScript ilə React:** TypeScript-in React layihələrində tətbiqi, tiplər, interfeyslər, enums.
3. **Komponent dizaynı:** Composition patterns, HOC, FunctionAsChild, Container vs Presentational.
4. **Hooks ekosistemi:** useState, useEffect, useMemo, useCallback, useReducer dərin analiz.
5. **Routing və data idarəsi:** React Router v6.4, Context API, SWR, Redux Toolkit.
6. **Server-Side Rendering:** SSR konsepti, Next.js ilə inteqrasiya.
7. **Real layihə:** GraphQL + Apollo + PostgreSQL + Sequelize + JWT ilə login sistemi.
8. **MonoRepo:** NPM Workspaces, Webpack konfiqurasiyası, shared packages.
9. **Testing:** Jest, Vitest, React Testing Library, DevTools.
10. **Deployment:** DigitalOcean, nginx, PM2, CircleCI.

## Nə öyrənilir?

- React 18-in yeni xüsusiyyətləri: Concurrent mode, Automatic batching, Suspense
- TypeScript-in React ilə inteqrasiyası və MonoRepo üçün tsconfig
- Müasir Hook patternləri və performans optimallaşdırması
- Real vaxt GraphQL API qurma (Apollo Server + Sequelize + PostgreSQL)
- NPM Workspaces ilə MonoRepo strukturu
- Production-grade CI/CD pipeline (CircleCI ilə)
