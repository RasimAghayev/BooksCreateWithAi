Добавление записей в конец журнала транзакций
Наш канал events  пока бездействует, что удручает. Хуже того, каналы даже 
не инициализированы. Давайте исправим этот недостаток, создав метод Run, 
как показано ниже:
func (l *FileTransactionLogger) Run() {
    events := make(chan Event, 16)     // Создать канал событий
    l.events = events
    errors := make(chan error, 1)      // Создать канал ошибок
    l.errors = errors
    go func() {
        for e := range events {        // Извлечь следующее событие Event
            l.lastSequence++           // Увеличить порядковый номер
            _, err := fmt.Fprintf(     // Записать событие в журнал
                l.file,
                "%d\t%d\t%s\t%s\n",
                l.lastSequence, e.EventType, e.Key, e.Value)
            if err != nil {
                errors <- err
                return
            }
        }
    }()
}
 Это весьма упрощенная реализация. Он не будет правильно обрабатывать записи 
с пробелами или с несколькими строками!
