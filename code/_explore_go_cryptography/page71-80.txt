func Crack(ciphertext, crib []byte) (key byte, err error) {
    for guess := range 256 {
        result := Decipher(ciphertext[:len(crib)], byte(guess))
        if bytes.Equal(result, crib) {
            return byte(guess), nil
        }
    }
    return 0, errors.New("no key found")
}

For simplicity, our tool also only accepts a crib that begins the plaintext. In
other words, we can’t use it to crack a ciphertext where we know part of the
middle, or the end, for example. The first byte of the crib must be the first
byte of the plaintext, or the tool won’t work.
Again, if you want to have some fun making this tool more flexible and
useful, you might like to think about ways to make it work with a crib that

text to check each key, but that’s okay. Slow deciphering is usually better
