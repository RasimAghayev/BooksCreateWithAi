### Test Structure
Tests follow the standard Go table-driven pattern:

```go
func TestTransactionService_Deposit(t *testing.T) {
    tests := []struct{
        name          string
        userID        uint64
        amount        float64
        setupMocks    func(*mocks.MockRepository, *mocks.MockKafkaPublisher)
        expectedError bool
        expectedResult model.TransactionDetails
    }{
        {
            name: "successful deposit",
            userID: 1,
            amount: 100.50,
            setupMocks: func(mockRepo *mocks.MockRepository, mockKafka *mocks.MockKafkaPublisher) {
                // Mock repository Deposit call
                mockRepo.EXPECT().
                    Deposit(gomock.Any(), expectedParams).
                    Return(expectedResult, nil)
                // Mock Kafka Publish call
                mockKafka.EXPECT().
                    Publish(gomock.Any(), "transaction_data", "1", gomock.Any()).
                    Return(nil)
            },
            expectedError: false,
            expectedResult: model.TransactionDetails{...},
        },
        {
            name: "repository error",
            userID: 1,
            amount: 100.50,
            setupMocks: func(mockRepo *mocks.MockRepository, mockKafka *mocks.MockKafkaPublisher) {
                mockRepo.EXPECT().
                    Deposit(gomock.Any(), expectedParams).
                    Return(model.TransactionDetails{}, errors.New("database error"))
                // Kafka Publish NOT called (error returned early)
            },
            expectedError: true,
        },
        {
            name: "kafka publish error",
            userID: 1,
            amount: 100.50,
            setupMocks: func(mockRepo *mocks.MockRepository, mockKafka *mocks.MockKafkaPublisher) {
                mockRepo.EXPECT().
                    Deposit(gomock.Any(), expectedParams).
                    Return(expectedResult, nil)
                // Kafka Publish fails → status updated to failed
                mockKafka.EXPECT().
                    Publish(gomock.Any(), "transaction_data", "1", gomock.Any()).
                    Return(errors.New("kafka error"))
                // UpdateTransactionStatus called to set status=failed
                mockRepo.EXPECT().
                    UpdateTransactionStatus(gomock.Any(), uint64(1), model.TransactionStatusFailed).
                    Return(nil)
            },
            expectedError: true,
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            ctrl := gomock.NewController(t)
            defer ctrl.Finish()
            mockRepo := mocks.NewMockRepository(ctrl)
            mockAccountService := mocks.NewMockAccountService(ctrl)
            mockKafka := mocks.NewMockKafkaPublisher(ctrl)
            logger := zerolog.Nop()
            
            tt.setupMocks(mockRepo, mockKafka)
            service := New(mockRepo, mockAccountService, mockKafka, &logger)
            result, err := service.Deposit(context.Background(), tt.userID, tt.amount)
            
            if tt.expectedError {
                assert.Error(t, err)
            } else {
                assert.NoError(t, err)
                assert.Equal(t, tt.expectedResult.Transaction.ID, result.Transaction.ID)
                assert.Equal(t, tt.expectedResult.Transaction.UserID, result.Transaction.UserID)
                assert.Equal(t, tt.expectedResult.Transaction.Amount, result.Transaction.Amount)
                assert.Equal(t, tt.expectedResult.Transaction.Status, result.Transaction.Status)
                assert.Equal(t, tt.expectedResult.Transaction.Type, result.Transaction.Type)
            }
        })
    }
}
```

### Test Cases Covered

#### TestTransactionService_Deposit
1. **Successful deposit**: Repository returns pending transaction, Kafka publish succeeds → returns pending transaction
2. **Repository error**: Repository fails to create transaction → returns error, no Kafka call
3. **Kafka publish error**: Repository succeeds, Kafka fails → status updated to `failed`, returns error

#### TestTransactionService_Withdraw
Same pattern:
1. **Successful withdraw**: Creates pending transaction, publishes to Kafka
2. **Repository error**: Repository fails → returns error
3. **Kafka publish error**: Kafka fails → UpdateTransactionStatus(failed), returns error

#### TestTransactionService_Transfer
1. **Successful transfer**: Creates pending transaction, publishes to Kafka
2. **Repository error**: Repository fails → returns error

#### TestTransactionService_HandleAccountResponse
Tests the response handler (processes Kafka responses from Account service):
1. **Successful response (completed)**: `result=true` → `UpdateTransactionStatus(completed)`
2. **Failed response**: `result=false` → `UpdateTransactionStatus(failed)`
3. **Repository error**: Update fails → returns error
4. **Invalid response - missing request_type**: Returns error early
5. **Invalid response - missing user_id**: Returns error early
6. **Invalid response - missing operation_id**: Returns error early

#### TestTransactionService_GetTransactionsWithDetails
1. **Successful get**: Retrieves transactions with details
2. **Repository error**: Returns error
3. **Transaction details error**: Skips failed transaction, continues with others

## Important Concepts

- **Table-driven tests**: Standard Go testing pattern — define test cases as a slice of structs
- **gomock**: Creates mock implementations of interfaces at test time
- **testify/assert**: Provides assertion functions (assert.NoError, assert.Equal, assert.Error)
- **Mock expectations**: `mockRepo.EXPECT().Deposit(gomock.Any(), expectedParams).Return(expectedResult, nil)`
- **Mock control**: `gomock.NewController(t)` + `defer ctrl.Finish()` verifies all expectations were met
- **zerolog.Nop()**: Creates a no-op logger for tests (no log output)
- **JSON marshaling**: AccountResponse is marshaled to JSON bytes to simulate Kafka message format

## Remember This

> Testing pattern: Table-driven + gomock mocks + testify assertions. Mock the Repository and KafkaPublisher interfaces, verify expected method calls, test both success and error paths.

## Terms

- **Table-driven test**: Go testing pattern with test cases as data structures
- **gomock**: Go mock framework for creating test doubles
- **testify/assert**: Go testing assertion library
- **MockController**: Manages mock lifecycle and verifies expectations
- **EXPECT()**: Sets expectation on mock object
- **EXPECT().Method().Return()**: Define what mock should return for a method call
- **ctrl.Finish()**: Verifies all expected calls were made
- **zerolog.Nop()**: No-op logger for test output suppression
- **Unit test**: Tests individual components in isolation with mocks
- **Mock**: Test double simulating interface behavior
- **Coverage profile**: HTML report showing code coverage (`go tool cover -html=coverage.out`)
