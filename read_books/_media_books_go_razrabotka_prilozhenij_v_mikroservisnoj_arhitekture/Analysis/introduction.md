## Introduction Summary

Kitabın əsas məqsədi: Mikroservislilərə sıfırdan gözələşməyin praktiki yolu — Go dilində. Kitab birmikrosfervisdən başlayır və bir neçə mikrosfervis, Kafka, Redis, Docker, Kubernetes ilə bağlandığına qədər inərək, hər şeyi əhatə edir.

Kitabın mövzu sırası:
1. Giriş və müqayəsə (monolitik vs mikrosfervis)
2. Birinci mikrosfervisin yaradılması (User)
3. Auth (avtorizasiya və autentikasiya)
4. Transaction
5. Deploy və ölçüklilaşdırma (Docker, Kubernetes)

## Target Audience

- Go dilində təcrübəliəlavəetməli web developer-lar
- Mikrosfervis arxitekturası ilə işləməyəlayıq olanlar
- Dağıtıq sistemlərinəmaraşıq olanlar

## Stack

Go, PostgreSQL, Kafka, Redis, Docker, Docker-Compose, Kubernetes — bu kitabda bütün bu texnologiyalar sırayla tətbiq olunacaq.
