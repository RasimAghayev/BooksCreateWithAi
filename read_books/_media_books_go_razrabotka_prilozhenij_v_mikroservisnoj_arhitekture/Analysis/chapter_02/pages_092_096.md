```go
type Config struct {
    ServiceName     string `env:"SERVICE_NAME" json:"service_name" required:"true" default:"auth-service"`
    AppEnv          string `env:"APP_ENV" json:"app_env" required:"true" default:"development"`
    Host            string `env:"GRPC_HOST" json:"host" required:"true" default:"localhost"`
    Port            int    `env:"GRPC_PORT" json:"port" required:"true" default:"50052"`
    LogLevel        string `env:"LOG_LEVEL" json:"log_level" required:"true" default:"info"`
    DbDsn           string `env:"DB_DSN" json:"db_dsn" required:"true"`
    JwtSecret       string `env:"JWT_SECRET" json:"jwt_secret" required:"true"`
    AccessTokenTTL  int    `env:"ACCESS_TOKEN_TTL_MINUTES" json:"access_ttl_min" required:"true" default:"60"`
    RefreshTokenTTL int    `env:"REFRESH_TOKEN_TTL_DAYS" json:"refresh_ttl_days" required:"true" default:"30"`
}

func Load() (*Config, error) {
    if err := godotenv.Load(); err != nil {
        log.Println("Warning: .env file not found, using system environment variables")
    }
    cfg := &Config{}
    if err := env.Parse(cfg); err != nil {
        return nil, err
    }
    return cfg, nil
}
```

```go
type User struct {
```

### Migrations (listing 2.5)
```go
func upInitDB(ctx context.Context, tx *sql.Tx) error {
    query := `CREATE TABLE IF NOT EXISTS users (
        id BIGSERIAL PRIMARY KEY,
        login TEXT NOT NULL UNIQUE,
        email TEXT NOT NULL UNIQUE,
        password_hash TEXT NOT NULL,
        created_at TIMESTAMP NOT NULL DEFAULT NOW(),
        updated_at TIMESTAMP NOT NULL DEFAULT NOW()
    );`
    _, err := tx.Exec(query)
    if err != nil {
        return err
    }
    query = `CREATE TABLE IF NOT EXISTS refresh_tokens (
        id BIGSERIAL PRIMARY KEY,
        user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
        token TEXT NOT NULL UNIQUE,
        expires_at TIMESTAMP NOT NULL,
        revoked_at TIMESTAMP NULL,
        created_at TIMESTAMP NOT NULL DEFAULT NOW()
    );`
    _, err = tx.Exec(query)
    return err
}
```

## What the Author Is Saying

> "Эта миграция, по сути, такая же, как и в Account, но с небольшим дополнением. Тут в рамках одной транзакции мы создадим сразу две таблицы и также две удалим, если что-то пойдет не так."

The migration creates both `users` and `refresh_tokens` tables in a single transaction — ensuring atomicity.

## Important Concepts

- **PasswordHash (not Password)**: The User model stores `password_hash` — bcrypt hash, never plaintext.
- **RefreshToken.Token**: Stores SHA-256 hash of the refresh token, not the raw token. Only the hash goes to the database.
- **RevokedAt**: Nullable field (`*time.Time`) — `NULL` means active, a timestamp means revoked (soft delete).
- **Foreign key**: `user_id BIGINT REFERENCES users(id) ON DELETE CASCADE` — deletes refresh tokens when user is deleted.
- **GORM implicit model**: When using `db.Create(&userRepo)`, GORM infers the model from the passed object. For queries, use `db.Model(&repomodel.User{})` to specify the schema explicitly.
- **Upsert**: `clause.OnConflict{UpdateAll: true}` handles unique constraint violations on login/email.

## Remember This

> Auth service config must include `JwtSecret`, `AccessTokenTTL`, and `RefreshTokenTTLDays` — these are essential for token lifecycle management.

> Refresh tokens are stored as SHA-256 hashes in the database — the raw token is only given to the user once.

## Terms

- **go mod init**: Initialize Go module
- **env package (caarlosO/env/v10)**: Environment variable parsing with struct tags
- **godotenv**: Load .env files

- **SHA-256**: Cryptographic hash function
- **Nullable field**: `*time.Time` maps to SQL NULL
- **Soft delete**: Marking records as deleted via timestamp instead of removing them

- **OnConflict**: SQL upsert behavior for conflict resolution

## Notes

- The User model is simpler than Account's (no phone, name fields) — Auth only needs login, email, password_hash.
- Migration naming convention: `20250825102441_initDB.go` — timestamp + name pattern.
- `ON DELETE CASCADE` ensures refresh tokens are cleaned up when users are deleted.
