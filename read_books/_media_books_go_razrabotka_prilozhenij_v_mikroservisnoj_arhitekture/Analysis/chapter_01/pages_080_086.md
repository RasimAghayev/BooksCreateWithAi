## Main Idea

Bu hissədə microservice-in test edilməsi Postman ilə necə edilir, gRPC request-ləri necə göndərilir və API-nın canlıca işlədilməsi göstərilir.

## What I Learned

### Postman CLI Testing (gRPC)
1. **Collection yaradın**: `Create Collection` → "microservices"
2. **Environment yaradın**: `No Environments` > `Create Environment` → "dev"
   - Variable: `account` → Initial value: `localhost:50051`
3. **gRPC request**: `New` > `gRPC` > URL: `(account)` — environment variable-ı ilə
4. **Proto fayl import**: `Service definition` tab > proto fayl yolunu göstərin
   - `import "account/account_model.proto"` olduqda, `account/` directory-ni göstərin (file deyil)

### Testing User CRUD
- **CreateUser**: gRPC request, message = `CreateUserRequest { user: { login, email, phone, first_name, ... } }`
  - Nəticə: `200 OK`, cavda `Empty`
- **GetUsers**: `GetUsersRequest { pagination: { limit: 20, offset: 0 } }`
- Screenshot 1.10: User yaradıldı, `status: OK`
- Screenshot 1.11: `GetUsers` ilə user listi pagination ilə

## Important Concepts

- **Postman gRPC testing**: `.proto`-ları import etmək, environment variables ilə URL idarə etmək.
- **Import path**: `import "account/account_model.proto"` olduqda, Postman-ı `account/` directory-ni (file deyil) göstərmək lazımdır.
- **Pagination testing**: `limit:20, offset:20` — səhifə keçidini test etmək üçün.

## Remember This

> gRPC API-nı Postman-lə test etmək: `gRPC` tab → proto fayl → `(env_var)` ilə URL. Import path-ləri directory olaraq göstərin.

## Terms

- Postman — API test tool (HTTP və gRPC dəstəyi)
- gRPC testing — gRPC request-ləri Postman ilə
- Service definition — Postman-ın `.proto`-ları oxumaq üçün tabı
- Environment variable — Postman-da URL parametrləri (dev, staging, prod)
- Collection — Postman-da request-lərin topluluğu
- Pagination testing — limit/offset ilə səhifələri test etmək
- Import path — proto faylları arası `import "..."` — directory əlaqəsi
