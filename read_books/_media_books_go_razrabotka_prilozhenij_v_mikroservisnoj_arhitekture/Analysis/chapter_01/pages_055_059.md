## Main Idea

Bu hissədə `.proto` faylları ilə API kontraktlarının necə versiyalandığı, Dockerfile+və Makefile ilə proto kodunun necə generate-olduğu və semantik versiyalanmanın (SemVer) əhmiyyəti izah edilir.

## What I Learned

### Protobuf Contracts
- `syntax = "proto3"` — modern proto versiyası
- `option go_package = "github.com/.../go;account"` — generate olunan Go package path-i
- `import "google/api/annotations.proto"` — HTTP mapping üçün (gRPC-gateway)
- `service Account { rpc CreateUser(...) returns (...) }` — RPC methodları
- `message User`, `message Pagination` — data struct-ları
- `option (google.api.http) = { post: "..." body: "*" }` — HTTP→gRPC mapping

### Code Generation (Dockerfile + Makefile)
- Dockerfile: `FROM golang:1.24`, `apt-get install unzip curl git`, `protoc` install, `git clone googleapis`, `go install protoc-gen-go`, `protoc-gen-go-grpc`
- Makefile `gen` target-i: `docker run --rm -v $(abspath $(PROTO_ROOT)):/app $(DOCKER_IMAGE) bash -c "..."` — containerdə protoc işə salır, `.proto` → `.go` generate edir
- `--go_out=go --go_opt=paths=source_relative` — generate parametrləri

### Versioning
- `git tag v1.0.0` — contract repo-suna yeni versiya
- `git push origin v1.0.0` — publish
- SemVer: `v1.0.0` → `v1.1.0` (yeni funksiya) → `v2.0.0` (breaking change)

## What the Author Is Saying

> "если два модуля не могут существовать один без другого, значит, модульность нарушена"

Proto faylları modul kimi baxılır — bir-birini import etməklə modulyarlıq poza.

> "Dockerfile и Makefile... превратить процесс сборки в предсказуемый и полностью автоматизированный"

Build reproducibility — Docker + Makefile ilə.

## Important Concepts

- **Proto module isolation**: `account_model.proto` və `pagination.proto` ayrılmış — ehtiyaç yoxdur ezgəsiz import.
- **Reproducible builds**: protoc versiyası + googleapis + plugins Docker containerdə sabit.
- **SemVer**: v1.0.0 (major.minor.patch) — major breaking, minor yeni funks, patch bugfix.
- **Contracts repo**: `github.com/yuliaapopova/contracts` — microservice-lər arası contract.

## Remember This

> `git tag v1.0.0 && git push origin v1.0.0` — contract repo-sunda versiya yarat. SemVer-ə uyğun.

## Terms

- Protocol Buffers (protobuf) — Google-nin binary serialization formatı
- Proto3 — protobuf syntax versiyası
- RPC — Remote Procedure Call
- Service (proto) — RPC methodlarının topluluğu
- Message — proto struct (protobuf ilə)
- Import — proto faylları arası bağımlılıq
- Annotation (google.api.http) — HTTP→gRPC mapping
- Dockerfile — Docker image build skripti
- Reproducible Build — hər yerdə eyni nəticə
- SemVer (Semantic Versioning) — versiya nömrələşdirəsi (MAJOR.MINOR.PATCH)
- Tag (git) — versiya işarəsi (git tag)
