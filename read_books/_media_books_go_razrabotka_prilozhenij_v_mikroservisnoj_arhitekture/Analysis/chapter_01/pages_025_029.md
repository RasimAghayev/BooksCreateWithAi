## Main Idea

Müəllif bizə API test vasitlarını (cURL, Swagger, Insomnia, Postman) təqdim edir, sonra mikrossfervis üçün optimal layihə strukturnı necə yaratmaq olduğunu izah edir. Go-da "framework" konsepsiyası yox idi — "bir avuç kiçik kitabxananı birlikdə toplayıb" arxitekturasiyası tətbiq olunur.

## What I Learned

### API Testing Tools
- **cURL**: 1996-cı ildə yayımlanıb, ən sadəliyi elə HTTP kliyi. Script-ələvə etmək çətindir.
- **Swagger UI**: OpenAPI specefikasiyası ilə fayl. "контрактқа слаживание" üçün istifadə olunur.
- **Insomnia**: Postman ilə eyni funksiyalara malik, lakin daha sadə.
- **Postman**: Seçilmiş vasitəl — "нам пригодится поддержка gRPC запросов, которой нет в Insomnia."

### Project Structure (Chapter 1)
Key principle: "Go не предоставляет инструментов автоматической генерации кода на уровне фреймворков" — bu, Go-nun fələncə olaraq "clean architecture" və ya "modular" yanaşmalarına səbəb edir.

**Recommended Go project structure:**

| Package | Purpose |
|---------|---------|
| `cmd/` | Entry points — `main.go` |
| `internal/` | Business logic (NOT importable externally) |
| `internal/service` or `internal/app` | Business logic — doesn't depend on infrastructure |
| `internal/model` | Data structures, entity files |
| `internal/repository` or `internal/storage` | Database interaction (CRUD) |
| `internal/api` or `internal/transport` | External interfaces — HTTP, gRPC, WebSocket handlers |
| `internal/migrations` | Database migrations |
| `internal/config` | Configuration parsing and validation |
| `pkg/` | Reusable code across services |

### Automation
**Dependency Injection (asılılıqların inyeksiyası)** konsepsiyası burada möcüzəvi olaraq görünmür — Go-lu developer-lar "интерфейси через конструктор" ilə asılılıqları ötürür.

## What the Author Is Saying

> "в Go считается правильным собирать проект из небольших библиотек, чтобы сохранять полную прозрачность и контроль над архитектурой."

Müəllif, Go-nun "böyük framework" yanaşmasından dəstək olur — bu, **Clean Architecture** və **Dependency Inversion** ilə uyğundur.

> "Весь код, относящийся к бизнес-логике, работе с базой данных, обращению к другим сервисам, помещается именно туда [internal]. Согласно соглашению Go всё, что находится в internal, не может быть импортировано извне."

Bu — **Information Hiding (məlumat gizlətmək)** prinsipidir. `internal` paketləri yalnız eyni modul içindən import oluna bilər.

## Important Concepts

- **Clean Architecture**: Business logic (`service`) infrastrukturadan asılı qalmız. `service` `interface`-lər vasitəsilə repository-ə baxır, `repository` konkret DB implementasiyasını göstərir.
- **Dependency Injection (asılılıqların inyeksiyası)**: Go-da "интерфейси через конструктор" — interfeys yaradıb, onu implementasiya edən obyekt konstruktorda ötürülür. Bu, test-lərdə mock-lamaq üçün idealdır.
- **Makefile**: "форматирование кода, запуск тестов, сборка, миграции, запуск линтеров, пересборка Docker-образов и деплой" — bu əmrləri avtomatlaşdırmaq üçün.

## Remember This

> `internal/` paketi Go-nun "модульная система" ilə işləyir — bu paketləri eyni moduldan başqa yerə import etmək olmaz. Bu, kodun bənzərliyini qorur.

> `cmd/` → `main.go` → `internal/` → `service/model/repository/api/config/pkg` — bu struktur "мikросервис должен расти без рефакторинга" tədbirləridir.

## Code

### 1. Project initialization
```bash
mkdir account && cd account
go mod init account
```

### 2. Project structure (recommended):
```
account/
├── cmd/
│   └── main.go          # Entry point — main() function
├── internal/
│   ├── service/         # Business logic
│   ├── model/           # Entity / DTO structures
│   ├── repository/      # Database interactions
│   ├── api/             # Transport layer (HTTP, gRPC handlers)
│   ├── migrations/      # Database migrations
│   └── config/          # Configuration
├── pkg/                 # Shared reusable code
├── go.mod
└── go.sum
```

### 3. main.go location
`main.go` — always in `cmd/` directory. This file:
- Sets configuration
- Starts the server
- Package must be `main` with `func main()`
