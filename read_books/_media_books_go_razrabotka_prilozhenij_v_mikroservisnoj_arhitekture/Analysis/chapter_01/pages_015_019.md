## Main Idea

Chapter 1-in bu hissəsində mikrossfervis inkiş etmək üçün vacib olan **local environment**-ı qurmağa başlanır. VS Code, Go, GVM, Protobuf, Git — bu alətlərin hamısı qurulur. Eyni zamanda, Go Modules-in köhnə menecerlarla (GODEP, glide, govendor) müqayəsi gedir.

## What I Learned

- **Go Modules** — bu günlər üçün standart asılılıq meneceri. `go.mod` və `go.sum` faylları ilə işləyir. Go 1.16-dan sonra default olur.
- **Köhnə menecerlər**: `GODEP`, `glide`, `govendor`, `dep` — hamısı arxivləşib. Bunların əvəzində `go.mod` istifadə edən Go Module ilə işləyirik.
- **go.mod formatı**:
  ```
  module github.com/username/myproject
  go 1.24.5
  require (
      github.com/pkg/errors v0.9.1
      github.com/rs/zerolog v1.33.0
  )
  ```
- **go.sum**: Hash kontrollu — `SHA-256` ilə `base64`-da kodlaşdırılmış. Supply Chain Attack-dan qorunur.
- **GVM (Go Version Manager)**: Go necəsənən idarə etmək üçün. Fərqli versiyalar arası keçiş. Version-u bir neçə addımda yuxarı çıxmaq lazımdır.
- **Protobuf (Protocol Buffers)**: gRPC üçün mesaj serializasiyası. `protoc` compiler və `protoc-gen-go` plugin-ləri.
- **Git**: `git init`, `git add`, `git commit`, `git branch`, `git checkout`, `git merge`, `git flow`.

## What the Author Is Saying

> "Этот менеджер позволяет управлять установленными версиями Go. В основном это актуально, когда ведется работа сразу над несколькими проектами и в них могут использоваться разные версии Go."

Müəllif, versiya meneceri olmağın vacibliyini vurğulayır — xüsusilə mikrosfervis layihələrində.

> "Код компилируется в машинный, а значит, приложения на Go обычно работают быстрее, чем те же самые решения, написанные на интерпретируемых языках (JS, Python)."

Go-nun compile-time üstünlüyünü vurğulayır.

## Important Concepts

- **Go Modules (`go.mod`)**: Go-un ehtiyat asılılıq meneceri. `go.sum`-də hash-lər saxlanılır.
- **Supply Chain Attack (təchizat zəncirinin hujumları)**: Asılılıq repozitoriyasından keçən hujumlardan `go.sum` ilə qorunur.
- **Git Flow**: `Master`, `Develop`, `Feature`, `Release`, `Hotfix` filialları.
- **Conventional Commits**: Commit mesajları üçün standart format.

## Remember This

> "go.mod" və "go.sum" — Go asılılıq menecerinin iki əsas faylı. go.sum təchizat zəncirinin təhlükəsizliyini təmin edir.

> Git Flow — "комплексный процесс управления ветвлением" — mikroservislərdə əla fikildir, çünktə çoxlu microservis var və hər biri üçün ayrı repo ola bilər.
