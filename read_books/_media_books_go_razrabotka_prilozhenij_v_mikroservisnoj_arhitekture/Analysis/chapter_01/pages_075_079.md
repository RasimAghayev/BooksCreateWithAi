## Main Idea

Bu hissədə `internal/app/app.go` DI container-ı təqdim edilir, `main.go` sadələşir, və graceful shutdown (`context.Context` + `GracefulStop`) ilə necə implementasiya edilir göstərilir.

## What I Learned

### DI Container (`internal/app/app.go`, listing 1.28)
- `App` struct: `cfg *config.Config`, `logger`, `accountRepository`, `accountService`, `accountServer`, `grpcServer`
- `New(&logger, cfg)` — minimal init (yalnız cfg və logger)
- `Run(ctx)`:
  1. `getAccountServer(ctx)` → `getAccountService(ctx)` → `getRepository(ctx)` → lazy chain
  2. `getRepository`: `gorm.Open` + `runMigrations` + `NewRepository`
  3. `getAccountService`: `service.New(repo, logger)`
  4. `getAccountServer`: `server.New(service, logger)`
  5. `getGRPCServer`: `grpc.NewServer()` + `RegisterAccountServer`
  6. `net.Listen("tcp", ...)` + `grpcServer.Serve(lis)`
- Lazy init: `if a.accountServer == nil` — birinci dəfə çağrıldıqda yaradılır

### Graceful Shutdown
```go
serveErrCh := make(chan error, 1)
go func() { serveErrCh <- a.grpcServer.Serve(lis) }()
select {
case <-ctx.Done():
    a.grpcServer.GracefulStop()
    return ctx.Err()
case err := <-serveErrCh:
    return err
}
```
- Context cancel olduqda (SIGINT/SIGTERM), `GracefulStop()` — açıq request-ləri tamamlayır.
- Həm server, həm də error channel-u `select` ilə handle olunur.

### Clean main.go (listing 1.29)
```go
func main() {
    ctx := context.Background()
    cfg, err := config.Load()
    if err != nil { panic(err) }
    l := logger.New(cfg)
    application := app.New(&l, cfg)
    if err := application.Run(ctx); err != nil {
        l.Fatal().Err(err).Msg("error")
    }
}
```

## What the Author Is Saying

> "В Go такой контейнер обычно делают руками, без магии и автогенерации"

Go-da DI container mașınla yazılır (manual), maşının yox. Bu, **eksplicit** və **transparent**-dır.

> "Вся инфраструктурная часть сосредоточена в одном месте... app.go играет роль каркаса"

`app.go` — bütün wiring-in məkanıdır, `main.go` sadəcə entry-point.

## Important Concepts

- **Lazy Initialization**: `getRepository` → `getAccountService` → `getAccountServer` — birinci çağrıldıqda init. `if nil` ilə yoxlanılır.
- **Graceful Stop**: `grpcServer.GracefulStop()` — context cancel ilə.
- **Manual DI**: Go-da framework yox (Spring Boot-ın əvəzinə), `app.go`-da manual wiring.
- **Migration run on startup**: `goose.UpContext(ctx, dbGoose, "internal/migrations")` — server başlayırda migration.

## Remember This

> `main.go` sadəcə entry-point olmalı. Bütün DI `internal/app/app.go`-da, oradan `newApp(ctx)` ilə başlayır.

## Terms

- DI Container — Dependency Injection kontekstı
- Lazy Initialization — tələsə-tələsə init (first call)
- Graceful Shutdown — açıq request-ləri tamamlayıb dayanmaq
- context.Context — Go-da cancellasiya və timeout üçün
- GracefulStop (gRPC) — gRPC server-ı təhlükəsiz dayanmaq
- Manual DI — framework-ləsiz asılılıq inject
- Transparent Code — kodun ehtiyatlarının aydın olması

## Notes

- `goose.UpContext(ctx, ...)` — context-aware migration. `goose.Up()` ilə fərqi: context ilə cancel/timeout dəstəyi.
