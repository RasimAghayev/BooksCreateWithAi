## Main Idea

Bu hissədə Go layihəsinin avtomatlaşdırılması (Makefile), environment dəyişənlərinin (env) idarə edilməsi (.env faylı) və Git-in ignore siyahısı (.gitignore) tam təsvir olunur.

## What I Learned

### Makefile
Ayrıca, Go-da "framework" yox, amma "automation via Makefile" vacibdir. Makefile-in əlavə seçimləri:

| Command | Purpose |
|---------|---------|
| `make build` | `go build` ilə binary yaradır |
| `make run` | `make build`-dan sonra işə salır |
| `make run-only` | Mövcud binary-ni işə salır |
| `make deps` | `go mod download` + `go mod tidy` |
| `make deps-update` | `go get -u ./...` + `go mod tidy` |
| `make fmt` | `gofmt`, `gofumpt`, `goimports` ilə formatlaşdırma |
| `make lint` | `golangci-lint` ilə linting |
| `make test` | `go test -v ./...` |
| `make test-coverage` | `go test -coverprofile` + HTML report |
| `make bench` | `go test -bench=...` |
| `make clean` | Build artefaktlarını silər |
| `make install` | `go install` ilə quraşdırma |
| `make dev` | `fmt lint test build` ardıcıllığı |
| `make ci` | CI/CD pipeline: `deps fmt lint test build` |

### Environment Variables (.env)
Müstəsna məlumatları kodda tutmaqla yanaşı, env dəyişənlərindən istifadə edilir:

```
BASE_SERVICE_NAME=account
APP_ENV=local
LOG_LEVEL=debug
HTTP_PORT=9000
HTTP_HOST=localhost
```

- `.env.example` — şablon faylı (commit olunur)
- `.env` — hər dev-da fərəqlidir, `.gitignore`-a daxil edilir
- Production, test environment-lər üçün fərəqli `.env` faylları

### .gitignore for Go
İdeal .gitignore üçün: binaries (*.exe, *.dll, *.so, *.dylib), test binary (*.test), coverage files (*.out, coverage.txt, coverage.html), dependency dirs, .env files, IDE files (.vscode, .idea), editor temp files (*.swp, *.swo, *~)

## What the Author Is Saying

> "Важнейшей частью любого Go-приложение является автоматизация рутинных задач"

Müəllif, automation-ın vacibliyini vurğulayır — "biz əmrləri xatırlayıb yazmağa getməyək, əks halda vaxt itirir" filiz.

> "хранить в самом коде [мел Axat] считается небезопасным" — secret-ləri kodda tutmamaq, env dəyişənlərində saxlamaq.

> ".gitignore обычно содержит файлы и каталоги, которые не предназначены для общего доступа" — bu, versiya nəzarətinin əsas prinsipidir.

## Important Concepts

- **CI/CD Pipeline (CI/CD çıxarılma)**: `make ci` target-i `deps fmt lint test build` ardıcıllığını ehtiva edir — bütün CI/CD-a dair əmrlər Makefile-ə yığılır.
- **Convention over Configuration (konvensiya konfiqurasiya)**: Go-da .gitignore, env faylları və Makefile standardı var.
- **Security by .env (təhlükəsizlik .env ilə)**: `.env` faylı `.gitignore`-a salınır, amma `.env.example` commit olunur.
- **Version Injection**: `LDFLAGS ?= -ldflags "-X main.Version=$(VERSION) -X main.BuildTime=$(BUILD_TIME)"` — build zamanı versiya və tarixi binary-ə əlavə edər.

## Remember This

> Makefile-in `.PHONY` hissəsi — "build run run-only deps..." — bu, make-in target-lərin (hər hansısa fayl yaradmayan) olduğunu göstərir.

> `.env.example` faylı **hər zaman** commit olunur; `.env` faylı **heç vaxt** commit olunmur.

## Code

### 1. Makefile (listing 1.2)
```makefile
# Go application Makefile
APP_NAME ?= account
BINARY_NAME ?= bin/$(APP_NAME)
MAIN_PATH ?= ./cmd
VERSION ?= $(shell git describe --tags --always --dirty 2>/dev/null || echo "dev")
BUILD_TIME ?= $(shell date -u '+%Y-%m-%d_%H:%M:%S')
LDFLAGS ?= -ldflags "-X main.Version=$(VERSION) -X main.BuildTime=$(BUILD_TIME)"

# Go files to format and lint
GOFILES ?= $(shell find . -name "*.go" -type f -not -path "./vendor/*" -not -path "./.git/*")

# Default target
.DEFAULT_GOAL := build

build:
	@echo "Building $(APP_NAME) ..."
	@mkdir -p bin
	go build $(LDFLAGS) -o $(BINARY_NAME) $(MAIN_PATH)

run: build
	@echo "Running $(APP_NAME) ..."
	./$(BINARY_NAME)

deps:
	@echo "Installing dependencies ..."
	go mod download
	go mod tidy

fmt:
	@echo "Formatting code ..."
	gofmt -s -w $(GOFILES)
	gofumpt -l -w -s $(GOFILES)
	goimports -l -w $(GOFILES)

lint:
	@echo "Running linter ..."
	golangci-lint run --timeout=10m -v ./...

test:
	@echo "Running tests ..."
	go test -v ./...

ci: deps fmt lint test build
	@echo "Running without building"

.PHONY: build run run-only deps deps-update fmt lint test test-coverage bench clean install docs help dev ci
```

## Notes

- `VERSION` в Makefile `git describe --tags --always --dirty` — bu Git tag-lərindən versiya almaq üçün. Bu, **GitOps** ilə bağlıdır.
- CI/CD pipeline (`make ci`) Git-dən asılı: `git describe --tags` ilə versiya. Bu, version-controlled deploy üçün vacib.
- env dəyişənlərinin `.env.example` faylında göstərilməsi — **Twelve-Factor App** prinsibinə uyğundur.
- `.env.production` faylının adı səhv yazılmış `(.env.developrnent)` — kitabın typo-si, lakin real faylın adı `.env.development` olmalı.
