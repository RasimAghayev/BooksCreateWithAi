## Main Idea

Bu hissədə Repository layının implementasiyası (GORM ilə CRUD əməliyyatları), goose ilə DB migrasiyaları və AccountService (business-logika) tam təqdim olunur.

## What I Learned

### Repository CRUD (listing 1.22)
Repository struct: `db *gorm.DB` + `logger *zerolog.Logger`

Metodlar:
- **CreateUser**: `Clauses(clause.OnConflict{UpdateAll: true})` — upsert (insert-or-update)
- **GetUser**: `Where("id = ?", userID).First(&user)` — `errors.Is(gorm.ErrRecordNotFound)` ilə error handle
- **GetUsers**: `Offset(offset).Limit(limit).Find(&users)` — pagination
- **DeleteUser**: `Where("id = ?", userID).Delete(&repomodel.User{})`
- **UpdateUser**: `Where("id = ?", userID).Updates(user)`

### Pagination
- `limit`: sətirlərin sayı (məsələn, 20)
- `offset`: başlanğıç nöqtəsi (1-ci səhifə: offset=0, 2-ci: offset=20)
- Frontend-in `Next` düyməsi → `limit:20, offset:20` → `limit:20, offset:40`

### Migrations (goose)
- `go install github.com/pressly/goose/v3/cmd/goose@latest`
- `goose -dir internal/migrations create initDB` — migration fayl generate edir
- `goose.AddMigrationContext(upInitDB, downInitDB)` — init() funksiyasında register
- `upInitDB`: `CREATE TABLE users (...) ` — yeni cədvəl/indeks yaradır
- `downInitDB`: `DROP TABLE IF EXISTS users` — rollback
- Migration faylları timestamp + ad ilə: `20250825102441_initDB.go`

## Important Concepts

- **Upsert** (`OnConflict`): `INSERT ... ON CONFLICT DO UPDATE` — idempotent insert.
- **gorm.ErrRecordNotFound**: record tapılmadığını göstərən error. `errors.Is()` ilə yoxlanılır.
- **Migration naming**: `timestamp_migrationName.go` — collision-ə qarşı təminat.
- **Service-Repository interface**: service biznes-logikada repository interface-ına istinətir, konkret implementation-ı bilinmir.
- **bcrypt**: `golang.org/x/crypto/bcrypt` — password hashing üçün.

## Remember This

> Repository error handling: `errors.Is(res.Error, gorm.ErrRecordNotFound)` — record tapılmadığında xüsusi error qaytar.
