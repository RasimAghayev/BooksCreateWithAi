## Main Idea

Bu hissədə Swagger ilə API-dokumentasiyası necə avtomatlaşdırılır, Gin ilə HTTP-server qurulur və PostgreSQL DB-nin əsasları izah edilir.

## What I Learned

### Swagger Documentation
Swagger — REST API-nin avtomatik dokumentasiyası üçün tool:
1. CLI setup: `go install github.com/swaggo/swag/cmd/swag@latest`
2. PATH-ə `export PATH=$PATH:$(go env GOPATH)/bin` əlavə et
3. Generate: `swag init -g cmd/main.go`
4. Serve: `localhost:9000/swagger/index.html` — bra brauzerdə API docs

### Gin HTTP Framework
- `go get github.com/gin-gonic/gin` — quraşdırmaq
- `router := gin.Default()` — default middleware-lə
- Radix Tree ilə marshrutlaşdırma — sürətli
- `router.GET("/swagger/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))`
- `router.GET("/ping", PingExample)` — health-check endpoint

### PostgreSQL DB Intro
DB-lə işlək iki üsul: fayllar və DB. DB, cədvəllər, sütunlar, sətirlər (Records/Rows) — əsas strukturlar.

### Types of Databases
- **Relational** — cədvəllər (users, orders), SQL ilə
- **NoSQL/Document** — JSON obyektləri (MongoDB kimi)
- **Key-Value** — Redis kimi
- **Graph** — graph struktur (social networklar)
- **Columnar** — analitik üçün

## Important Concepts

- **SWAGGER CLI**: `swag init -g cmd/main.go` — koddan `@Summary`, `@Success`, `@Router` comment-lərini oxuyur.
- **Gin @title, @version comment tags** — `cmd/main.go`-nun üstündə Swagger metadata.
- **DB Types**: Relational (PostgreSQL), Document (Mongo), K/V (Redis), Graph, Columnar.

## Remember This

> Swagger, `@tag` ilə annotasiya olunmuş kodla `swag init` ilə generate olunur. Bu, **"documentation-as-code"** prinsibidir.

## Terms

- Swagger / OpenAPI — REST API dokumentasiyası üçün standart
- swag — Go Swagger generator
- Gin — HTTP web framework (Radix Tree router)
- Radix Tree — sürətli prefix axtarış ağacı
- PostgreSQL — açıq mənbə relational DB (SQL)
- NoSQL — non-relational DB-lər (document, key-value, graph, columnar)
- Document DB — JSON obyektləri (MongoDB)
- Key-Value — Redis, DynamoDB
- Graph DB — Neo4j, Amazon Neptune
- Columnar DB — Cassandra, ClickHouse (analitik üçün)
- Normalization (нормализация) — DB strukturunu standardlaşdırma
