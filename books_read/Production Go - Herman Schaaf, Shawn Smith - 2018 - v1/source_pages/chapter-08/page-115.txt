This time our function used 132 bytes per operation, due to our use of a slice in the function. If
you are wondering why the number is 132 specifically: the exact number of bytes is sensitive to
the numbers we use in the benchmark. The higher the input n, the more memory the function will
allocate. The average of the values used in the benchmark (0, 10, 20, 30) is 15. Because this was
compiled for a 64-bit machine, each int will use 8 bytes (8x8=64 bits). The slice headers also use
some bytes. We still have zero heap allocations per operation, due to all variables being contained
within the function. We will discuss advanced memory profiling and optimization techniques in
Optimization.
