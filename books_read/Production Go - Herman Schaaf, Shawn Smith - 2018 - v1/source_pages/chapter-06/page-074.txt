Concurrency
Go’s concurrency model is based on what are called “goroutines” - essentially lightweight threads.
To invoke a goroutine, we use the go keyword:
go func() {
fmt.Println("hello, world")
}()
If we were to add the above to a main() function and run it, we would probably see no output. This
is because the main exited before the goroutine had time to finish. To see this in action, let’s add a
sleep to give the goroutine some time to run:
