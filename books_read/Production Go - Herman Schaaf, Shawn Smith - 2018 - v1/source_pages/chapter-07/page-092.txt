Writing error messages
In the tests above, we had the following code:
if got != c.want {
t.Errorf("IsPrime(%d) = %t, want %t", c.give, got, c.want)
}
The ordering of the if statement is not accidental: by convention, it should be actual != expected, and
the error message uses that order too. This is the recommended way to format test failure messages
