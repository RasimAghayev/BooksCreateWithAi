Unlike the other signed integer types, the int type does not explicitly state its width. This is because
it acts as an alias for either int32 or int64, depending on the architecture being compiled to. This
means that it will perform optimally on either architecture, and it is the most commonly used integer
type in Go code.
Go does not allow implicit type conversions. When converting between integer types, an explicit
type cast is required. For example, see the following code:
