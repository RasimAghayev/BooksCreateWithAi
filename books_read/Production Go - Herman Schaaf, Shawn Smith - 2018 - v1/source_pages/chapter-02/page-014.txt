We can run our code with go run main.go. The other option is to build our code as an executable
and run that. To do that, we first run go build to make sure that the code compiles. Then we run go
install:
$ go build
$ go install
$ cd $GOPATH/bin
$ ./dinner
We'll have pizza for dinner tonight!
We can also run these commands from outside of our GOPATH, like so:
$ go build github.com/prodgopher/dinner
$ go install github.com/prodgopher/dinner
