Lastly, there is no pointer arithmetic in Go. The authors decided to leave it out for reasons such as
safety, and simplifying the implementation of the garbage collector.¹¹
Goroutines
Goroutines are functions that run concurrently in a Go program. They are lightweight, and cheap
to use. Prefixing a function with the go keyword will run the function in a new goroutine:

should not be considered a valid way of managing goroutines.)
