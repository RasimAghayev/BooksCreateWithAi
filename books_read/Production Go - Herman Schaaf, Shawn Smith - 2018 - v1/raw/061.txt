The strings.Split function takes a string and a separator as arguments. In this case, we passed in
"a,b,c" and the separator “,” and received a string slice containing the separate letters a, b, and c as
strings.
Counting and finding substrings
Using the strings package, we can also count the number of non-overlapping instances of a substring
in a string with the aptly-named strings.Count. The following example uses strings.Count to count
occurrences of both the single letter a, and the substring ana. In both cases we pass in a string²¹.
Notice that we get only one occurrence of ana, even though one may have expected it to count
ana both at positions 1 and 3. This is because strings.Count returns the count of non-overlapping
occurrences.
