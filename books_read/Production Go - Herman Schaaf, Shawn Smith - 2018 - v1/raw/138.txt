Continuous Integration
In this chapter, we will explore the topic of continuous integration (CI). Continuous integration is a
general term that describes the process of running tests and builds automatically whenever a team
member adds new code to the codebase. Continuous integration in a production-ready Go system
often also includes running miscellaneous checks and linters.
It is possible to write your own continuous integration system, but the effort is likely not worth
it. There are many existing continuous integration systems out there. Some, like Travis CI, are
hosted for you and are free for open source projects. Others, like Drone, are open source and free for
self-hosting, but also comes with enterprise versions. We tabulated some popular alternatives that

Of the above four options, we recommend using either Travis CI or Drone CI, mostly for their relative
simplicity. We will first discuss the more famous Travis CI in more detail, and then move on to the
under-appreciated (but amazing) Drone CI.
