res, err := SendRequest()
base, cap := time.Second, time.Minute
for backoff := base; err != nil; backoff <<= 1 {
    if backoff > cap {
        backoff = cap
    }
    jitter := rand.Int63n(int64(backoff * 3))
    sleep := base + time.Duration(jitter)
    time.Sleep(sleep)
    res, err = SendRequest()
}

 Функции в пакете rand создают детерминированную последовательность значений 
при каждом запуске программы. Если не использовать функцию rand.Seed, чтобы за-
дать новое начальное значение, то они всегда будут действовать так, как если бы 
был выполнен вызов rand.Seed(1), и всегда производить одну и ту же «случайную» 
последовательность чисел.
