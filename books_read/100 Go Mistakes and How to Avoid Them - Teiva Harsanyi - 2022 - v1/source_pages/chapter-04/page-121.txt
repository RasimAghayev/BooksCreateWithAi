example that updates a specific array index during the iteration:
a := [3]int{0, 1, 2}
for i, v := range a {
a[2] = 10
if i == 2 {
fmt.Println(v)
}
}
This code updates the last index to 10. However, if we run this code, it does not print
10; it prints 2, instead, as figure 4.3 shows.
As we mentioned, the range operator creates a copy of the array. Meanwhile, the loop
doesn’t update the copy; it updates the original array: a. Therefore, the value of v
during the last iteration is 2, not 10.
 If we want to print the actual value of the last element, we can do so in two ways:
By accessing the element from its index:
a := [3]int{0, 1, 2}
for i := range a {
a[2] = 10
if i == 2 {
fmt.Println(a[2])
}
}
