Data types
Dealing with data types is a frequent operation for software engineers. This chapter
delves into the most common mistakes related to basic types, slices, and maps. The
only data type that we omit is strings because a later chapter deals with this type
exclusively.

put of the following code?

fmt.Println(sum)
