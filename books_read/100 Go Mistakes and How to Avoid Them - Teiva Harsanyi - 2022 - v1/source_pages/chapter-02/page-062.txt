 Another option is to use the classic builder pattern, as presented in the next section. 
2.11.2 Builder pattern
Originally part of the Gang of Four design patterns, the builder pattern provides a flexi-
ble solution to various object-creation problems. The construction of Config is sepa-
rated from the struct itself. It requires an extra struct, ConfigBuilder, which receives
methods to configure and build a Config.
 Let’s see a concrete example and how it can help us in designing a friendly API
that tackles all our requirements, including port management:
type Config struct {
Port int
}
type ConfigBuilder struct {
port *int
}
func (b *ConfigBuilder) Port(
port int) *ConfigBuilder {
b.port = &port
return b
}
func (b *ConfigBuilder) Build() (Config, error) {
cfg := Config{}
if b.port == nil {
cfg.Port = defaultHTTPPort
} else {
if *b.port == 0 {
cfg.Port = randomPort()
} else if *b.port < 0 {
return Config{}, errors.New("port should be positive")
} else {
cfg.Port = *b.port
}
}
