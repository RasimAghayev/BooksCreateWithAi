Struct Maps with Array Values
In order to assign multiple values to a map key, the valueType must be an array, with the general
form of:
1
map[keyType][]valueType
Noticed that we prepended the [] before the valueType. In Go, this is a general form to define
an array. In Ruby, arrays are also defined with an open and closing square brackets [], in Go, the
brackets needs to be explicitly defined in front of the valueType to form an array.
This form of defining an array is not only applicable to maps, but can also be the same way to
initialize an array in variables and function arguments.
Using map by assignment, we can assign multiple values to a key. In our Ruby and Golang
comparison in the first section of this article, we can rewrite our Ruby code above to the following
Golang syntax:
