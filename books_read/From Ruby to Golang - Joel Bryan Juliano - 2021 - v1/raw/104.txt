Detect Enumerable Method
If you want to return the first item that satisfies a condition, use Detect. In the following example,
detect returns the processed value in the block.
1
(1..10).detect
{|i| i % 5 == 0 and i % 7 == 0 }
#=> nil
2
(1..100).detect {|i| i % 5 == 0 and i % 7 == 0 }
#=> 35
