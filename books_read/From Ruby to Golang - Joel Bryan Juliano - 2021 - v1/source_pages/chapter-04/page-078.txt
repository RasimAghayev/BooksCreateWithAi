In this example, we have fruits ...string argument in the basket function, which acts as a similar
to the splat operator in Ruby. Then we iterate over the fruits array and print them. If you would pass
an array variable to another function accepting a variadic argument, you would need to pass the
variable proceeded with three dots .... For example, on line 16, we pass the variadic fruits... to
the basket function.
