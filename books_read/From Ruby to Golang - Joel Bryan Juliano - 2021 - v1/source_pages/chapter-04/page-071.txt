Questions
1. What have we learned?
Sliced array is reference types, so when we assign a sliced array to a new variable, we are not
creating a new copy of the original array, but instead, we are creating a new variable that
points to the same array as the original variable.
2. Why is this useful?
This is useful because it is much more efficient and cheaper to use sliced array than creating
a new copy of the original array.
3. What is the assignment behaviour of a sliced array?
When we assign a sliced array to a new variable, the new variable will point to the same
array as the original variable.
Capacity
In Go, there is a third parameter when creating a Slice Array using make. Make takes the following
parameters.
1
make(type, length, capacity)
By default, when you initialized a sliced array without specifying the third parameter, it would
automatically take the second parameter as the value of the third, so
1
array := make([]string, 2)
is the same as
1
array := make([]string, 2, 2)
