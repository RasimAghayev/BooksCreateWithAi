Questions
1. What have we learned?
We can use append to extend an array.
2. Why is it useful?
Appending an array is useful when we need to extend an array to a new variable.
3. What are the dangers of using array append?
If we append to an array that is not large enough to hold the new values, the array will be
reallocated and the old values will be lost.
