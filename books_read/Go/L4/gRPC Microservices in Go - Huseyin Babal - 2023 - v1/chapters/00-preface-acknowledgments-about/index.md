# Chapter 0 — Preface / Acknowledgments / About (Ön söz / Minnətdarlıq / Haqqında)

## Bu chapter nədən bəhs edir?
Müəllifin mikro servis səyahətinə, kitabın strukturu və auditoriyasına, kod nümunələrinin icra üsuluna (GitHub Actions) və müəllif haqqında məlumata.

## Əsas fikirlər

### Preface (Ön söz)
Müəllif Hüseyin Babal 2007-dən developer-dir; 2014-dən mikro servislərin tərəfdarı. Kitabın yanaşması:
- **E-commerce tətbiqi** kitab boyu nümunə layihə kimi (Kubernetes üzərində deploy)
- Praktik best practice-lər — production-grade texnikalar
- İrəli mövzular: error handling, testing, security

### About this book (Kitab haqqında)
3 hissəli strukturl:
- **Part 1:** gRPC və mikro servis arxitekturası (nəzəriyyə: monolith→microservices, saga, gRPC giriş)
- **Part 2:** gRPC mikro servis tətbiqinin inkişafı, testi və deployu (praktiki: proto→layihə→kommunikasiya→resiliency→test→K8s)
- **Part 3:** gRPC və mikro servis arxitekturası (observability)

### Kod nümunələrinin icrası (bütün kitab üçün)
GitHub repo fork et → Actions workflow `listing_execute.yaml` işə sal → listing nömrəsini ver (məs. 2.1) → çıxışı Run step-də gör.
Bu, kitabın kodunu lokalda quraşdırmadan icra etməyin yolu.

### About the author
Hüseyin Babal — software architect; mikro servislər, gRPC, K8s ekosistemində təcrübə; training/speaker.

## Praktik nəticə
Kitabı oxuyarkən kod nümunələrini GitHub Actions ilə icra etmək ən sürətli yol — lokal mühit qurmadan listing çıxışlarını görün.
