In the next step, we are going to add the repository implementation. Even if you have some specific 
technology to work with for storing the data, it is often useful to provide more than one implementation 
of the database logic. I always find it useful to include an in-memory implementation of the database 
logic that can be used for testing and local development, reducing the need for any additional databases 
or extra libraries. I am going to illustrate how to do this.
Inside the metadata/internal/repository directory, create a directory called memory that 
will contain the in-memory implementation or our movie metadata database. Add a memory.go 
file to it, using the following code:
