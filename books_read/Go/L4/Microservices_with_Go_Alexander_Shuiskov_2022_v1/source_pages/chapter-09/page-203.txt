You may notice that we used the cmpopts.IgnoreUnexported(gen.Metadata{}) option 
inside the call to the cmp.Diff function — this tells the cmp library to ignore the unexported 
fields in the gen.Metadata structure. We have added this option because the gen.Metadata 
structure, generated by the Protocol Buffers code generator, includes some private fields that we want 
to ignore in the comparison.
