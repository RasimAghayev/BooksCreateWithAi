Table 7.2 – Rating table example
Using SQL language, we can write a more complex query to get all ratings that are associated with 
movies of a certain director:
SELECT * FROM ratings r INNER JOIN movies m ON r.record_id = 
m.id WHERE r.record_type = "movie" AND m.director = "Ben Miles"
In our SQL query, we perform a join of two tables – an operation that allows us to group the data 
belonging to two tables and perform additional filtering (in our case, we will only select rating events 
where the record_type column’s value is equal to movie and the director column’s value is equal to 
Ben Miles).
