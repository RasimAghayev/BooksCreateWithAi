Summary
In this chapter, we provided a brief overview of database storage solutions for storing microservice 
data. We illustrated how to write the logic for writing and reading our service data into MySQL, a 
popular open source relational database that is widely used across the software development industry. 
In the next chapter, we are going to illustrate how to build and run our service instances using a 
popular platform, Kubernetes, that allows us to coordinate various service-related operations, such
