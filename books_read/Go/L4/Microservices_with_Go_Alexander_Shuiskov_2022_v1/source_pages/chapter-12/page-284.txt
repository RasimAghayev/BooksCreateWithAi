Next, we will demonstrate how to scrape a static list of service instances; you can try setting up Consul-
based Prometheus scraping as an additional exercise after reading this chapter. Let’s add alerting rules 
for our services. Inside the newly added configs directory, create the alerts.rules file and 
add the following to it:
groups:
- name: Service availability
  rules:
  - alert: Metadata service down
    expr: up{service="metadata"} == 0
    labels:
      severity: warning
    annotations:
      title: Metadata service is down
      description: Failed to scrape {{ $labels.service }}.
