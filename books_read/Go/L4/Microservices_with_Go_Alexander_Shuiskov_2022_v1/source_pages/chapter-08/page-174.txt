Import it into our module by running the following command:
go mod tidy
Make the same changes that we just made for the other two services we created earlier. Use port number

The changes we just made helped us introduce the application configuration that is separate from 
the service logic. This can help us when we want to introduce additional configurable options—to 
make any configuration changes, we would just need to update the YAML files without touching our 
service Go code.

Deploying via Kubernetes
