Now, create a file with the same name in the rating service directory with the following 
contents:
apiVersion: apps/v1
kind: Deployment
metadata:
  name: rating
spec:
  replicas: 2
  selector:
    matchLabels:
      app: rating
  template:
    metadata:
      labels:
        app: rating
    spec:
      containers:
      - name: rating
        image: <Your Docker username>/rating:1.0.3
        imagePullPolicy: IfNotPresent
        ports:
          - containerPort: 8082
Remember to replace the image property with the Docker image name that you created in step 4.
