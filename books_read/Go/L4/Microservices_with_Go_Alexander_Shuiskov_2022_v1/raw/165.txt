// Put adds movie metadata for a given movie id.
func (r *Repository) Put(ctx context.Context, id string, 
metadata *model.Metadata) error {
    _, err := r.db.ExecContext(ctx, "INSERT INTO movies (id,

In our code, we implemented the Get and Put functions so that we can store and retrieve the movie 
metadata from MySQL. Inside our Get function, we use the QueryRowContext function of our 
database instance to read a single row from our table. In the case of a query error, we check if it is 
equal to sql.ErrNoRows; if so, we return ErrNotFound.
