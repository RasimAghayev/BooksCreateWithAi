The file we just added includes the alert definitions for each of our services. Each alert definition 
includes the expression Prometheus would check to evaluate whether an associated alert should be fired.
Now, we are ready to install and run Prometheus to test our alerting. Inside the src directory of 
our project, run the following command to run Prometheus using the newly created configuration:
docker run \
    -p 9090:9090 \
    -v configs:/etc/prometheus \
    prom/prometheus
If everything is successful, you should be able to access the Prometheus UI by opening http://
localhost:9090/. On the initial screen, you will see the search input you can use to access the 
Prometheus metrics emitted by our services. Type up into the search input and click Execute to 
access the metrics:
