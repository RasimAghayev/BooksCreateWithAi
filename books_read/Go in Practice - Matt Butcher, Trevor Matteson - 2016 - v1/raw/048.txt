Alternately, an application can be built and run as in the following listing.
$ go build inigo.go
$ ./inigo
Here the first step is to build the application. Using go build without filenames will
build the current directory. Using a filename, or set of filenames, only builds the selec-
tion. From there, the built application needs to be executed.
