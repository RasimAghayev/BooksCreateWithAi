10.3
Summary
In this chapter, you explored REST communications and faster alternatives. These
alternatives, or similar options, are used by Google, Facebook, and others that operate
using many discrete services that need to work together. The techniques you learned
about include the following:
Communications in a microservice architecture and how that can be a bottleneck
Reusing connections to improve performance by avoiding repeated TCP slow-
start, congestion-control ramp-ups and connection negotiations
Faster JSON marshaling and unmarshaling that avoids extra time spent reflecting
Using protocol buffering instead of JSON for messaging
Communicating over RPC using gRPC
In the next chapter, you’ll learn about reflection and metaprogramming in Go. That
includes using tags on structs and code generation.
