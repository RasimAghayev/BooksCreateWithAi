TECHNIQUE 43
Serving from an alternative location
enables safe development and testing whereby a slip-up in development or testing
doesn’t impact production users.
 When the location of the files is different in each environment, the location needs to
be passed into the application as configuration. This can happen via a shared configu-
ration service such as etcd, in configuration files, as arguments passed into the applica-
tion at startup time, or some other means of passing configuration. The following
listing provides a basic example of passing a location in as a command-line argument.
var t *template.Template
var l = flag.String("location", "http://localhost:8080", "A location.")
var tpl = `<!DOCTYPE HTML>
<html>
  <head>
    <meta charset="utf-8">
    <title>A Demo</title>
    <link rel="stylesheet" href="{{.Location}}/styles.css">
  </head>
  <body>
    <p>A demo.</p>
  </body>
</html>`
func servePage(res http.ResponseWriter, req *http.Request) {
     data := struct{ Location *string }{
          Location: l,
     }
     t.Execute(res, data)
}
