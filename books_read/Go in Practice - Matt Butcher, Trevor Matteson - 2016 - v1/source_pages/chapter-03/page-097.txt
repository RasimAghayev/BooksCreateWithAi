Concurrency in Go
package main
import (
     "fmt"
     "os"
     "time"
)
func main() {
     done := time.After(30 * time.Second)
     echo := make(chan []byte)
     go readStdin(echo) 
     for {
            select {
            case buf := <-echo:
                   os.Stdout.Write(buf)
            case <-done:
                   fmt.Println("Timed out")
                   os.Exit(0)
            }
     }
}
func readStdin(out chan<- []byte) {
     for {
            data := make([]byte, 1024)
            l, _ := os.Stdin.Read(data)
            if l > 0 {
                   out <- data
            }
     }
}

Timed out
As you saw with the previous implementation, if you type test 1, that text is echoed
back. After 30 seconds, the program halts itself.
 Rewriting the echo example has introduced new concepts regarding channels. The
first channel in the preceding code is created by the time package. The time.After
function builds a channel that will send a message (a time.Time) when the given dura-
tion has elapsed. Calling time.After(30 * time.Second) returns a <-chan time.Time
