Getting into Go
The way we build and run software is changing. Innovation has swept in, disrupting
long-standing assumptions about the computing environments that software runs
in. To fully take advantage of these innovations, you need languages and tools that
support them at their core.
 When most mainstream programming languages and supporting toolchains
were developed, they were designed for single-core processing. That’s what we had.
Now desktop computers, servers, and even our phones have processors with multi-
ple cores. Running software with operations taking place concurrently can happen
anywhere.

and complexity in software requires environments that can build and execute the
code rapidly and efficiently. Testing larger and more complicated codebases needs
