The preceding code starts the handlers.Login function by creating a new
renderings.LoginResponse and a new bindings.LoginRequest, which we then
bind our request data from the HTTP request to. Echo has a c.Bind function on
the Echo Context type, which takes the input from the request and populates the
bindings.LoginRequest we pass in. After we bind and validate our structures,
we perform the business logic of getting the user from the database. We perform
a bcrypt operation, and, upon success, we generate a new JWT token which will
be the authentication token returned to the user.
Handlers are where the business logic happens, and routing is how handlers are
run in our service. The essence of a web application or API is confined within
these two basic primitives.
