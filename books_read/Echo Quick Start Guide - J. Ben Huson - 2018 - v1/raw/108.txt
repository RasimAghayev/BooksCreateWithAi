Globally requesting context mapping
Within a global request to request a context mapping solution, there is a single
data structure in which you can look up the context for a request. The most
popular implementation of this can be found within the Gorilla web toolkit,
which can be found here: https://github.com/gorilla/context.
At a very high level, this code creates a single
map[*http.Request]map[interface{}]interface{} global variable, which is available
through the helper Get and Set functions. When used, if you 'Set' some contextual
variable, the code will create a new map[interface{}]interface{}, and uses the
request pointer of the request the contextual information belongs to as a map key
in the global map, the value of which would be the newly created
map[interface{}]interface{}. Then, the set call would add the key/value pair to the
