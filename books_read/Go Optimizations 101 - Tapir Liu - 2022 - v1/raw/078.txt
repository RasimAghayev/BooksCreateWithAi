8.2
Using slice-to-array-pointer conversions introduced in Go
1.17 to copy slices
Go 1.17 introduces a slice to array pointer conversion. We can make use of such conversions to
copy slices. It is found that, on any platform, the conversion way is more performant than the builtin
copy function if the sum element sizes of the copied slices are not larger than 64.
package arrays
import "testing"
const N = 64
var r []byte
var s = make([]byte, N)
func init() {
println("============= N =", N)
r = make([]byte, N)
}
func copy2(d, s []byte) {
*(*[N]byte)(d) = *(*[N]byte)(s)
}
func Benchmark_Copy(b *testing.B) {
for i := 0; i < b.N; i++ {
copy(r, s)
}
}
func Benchmark_Copy2(b *testing.B) {
for i := 0; i < b.N; i++ {
copy2(r, s)
}
}
