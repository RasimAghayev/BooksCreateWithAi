Please note that, as of Go toolchain v1.19, the two hints used in the f4c and f4d functions are not
workable (but they should).
In the following example, by adding a redundant if code block in the function NumSameBytes_2,
all bound checks in the loop are eliminated.
type T = string
func NumSameBytes_1(x, y T) int {
if len(x) > len(y) {
x, y = y, x
}
for i := 0; i < len(x); i++ {
if x[i] !=
y[i] { // Found IsInBounds
return i
}
}
