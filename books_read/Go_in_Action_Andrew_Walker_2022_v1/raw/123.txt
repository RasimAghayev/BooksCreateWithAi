Because these are just arrays of arrays, you can simply add another set of
brackets to access the inner values:
Listing 4.22. Accessing Elements Of A Two-Dimensional Array
// Declare a two dimensional integer array of two elements.
var array2D [2][2]int
// Set integer values to each individual element.
array2D[0][0] = 10
array2D[0][1] = 20
array2D[1][0] = 30
array2D[1][1] = 40
