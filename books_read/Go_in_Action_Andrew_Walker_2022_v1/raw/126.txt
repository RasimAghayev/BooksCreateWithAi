4.1.7 Passing Arrays To Functions
Passing an array value to a function can be a an expensive operation in terms
of performance and memory usage if you’re not careful. This is because all
values in Go are passed by value, so every time you pass an array to a
function, your program will copy the entire array and pass it to the function,
regardless of how large it is.
For example, let’s say you have a large array representing a 4K image, and
you want to pass those to a function for processing. That’s 3840 x 2160,
which is around 8.2 million pixels.
Listing 4.26. Passing A Large Array By Value To A Function
// image4K is a large array representing a 4K image #1
type image4K [829400]int // 3840 * 2160
func processPixels(pixels image4K) image4K {
// Image Processing Code Here.
return pixels
}
func main() {
var pixels image4K
pixels = processPixels(pixels)
}
