It’s super easy to use interfaces in Go, since any type will "just work" as a n
interface value, provided it matches the types. There’s no need to explicitly
declare that a particular class implemented the Describer interface, the
compiler can figure that out all on its own! As long as your type implements
an interface, it’s good to go.
Interfaces are a powerful tool, and you will learn more about them in
Chapter 5, which takes a deeper dive on the type system.
