You can try and get around this by adding extra capacity in main before
calling the function, but this doesn’t quite work either:
Listing 4.44. Attempting To Avoid The Append Allocation With Extra Capacity
func main(){
// Create A Slice With Extra Capacity
slice := make([]int, 0, 4)
slice[0] = 1
slice[1] = 2
slice[2] = 3
addOneToAll(slice)
fmt.Println(slice)
}
Listing 4.45. Output After addOneToAll With Extra Capacity
[2 3 4]
The values were incremented, but the final value is missing. This is because
the length of the original slice in main remains the same, meaning it cannot
"see" the new value.
