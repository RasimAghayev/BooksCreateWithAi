2.4.10 Basic For Loops
Listing 2.16. Looping Over String Characters With A for Loop
for i := 0; i < len(text); i++ {

}
}
The next step in the process is to look at each character in the string to see if
it’s a space or not. For this, you need a loop.
While other languages provide multiple looping constructs such as while and
do..while, Go unifies all of these into the for statement.
