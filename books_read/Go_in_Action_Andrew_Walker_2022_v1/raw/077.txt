When doing bitwise operations on unsigned values, the opposite advice
applies to picking a signed type: you will probably want to stick to sized
variants for these kinds of operations. This is because they will be exact sizes,
and this almost always what you want when doing bit manipulation, since it
will model the data in memory more precisely. The uint type doesn’t provide
this, because its length will change depending on the architecture, so you
won’t have as much use for it.
