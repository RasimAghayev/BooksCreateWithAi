If the array value is a pointer, the value of that pointer can be accessed using
the indirection operator, like you learned in Chapter 3.
Listing 4.10. Accessing Array Pointer Elements
// Declare an integer pointer array of five elements.
// Initialize index 0 and 1 of the array with integer pointers.
ptrArray := [5]*int{0: new(int), 1: new(int)}
// Assign values to index 0 and 1.
*ptrArray[0] = 10
*ptrArray[1] = 20
