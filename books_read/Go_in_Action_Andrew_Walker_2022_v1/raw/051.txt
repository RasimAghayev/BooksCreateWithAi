2.7.2 Avoiding A Panic By Using len
Because os.Args will always contain the name of your program first, you
need to look at os.Args[1] and above if you want to get at any of the
arguments, but there’s a catch: if your program isn’t run with any arguments
you could end up trying to access a value which doesn’t exist!
