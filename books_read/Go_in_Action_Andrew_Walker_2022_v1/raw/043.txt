Listing 2.20. Altering main.go to use strings.Fields And `len
package main
import (
"fmt"
"strings"
)
func main() {
text := "let's count some words!"
words := strings.Fields(text)
fmt.Println("Found", len(words), "words")
}

2.5.1 Introducing Package strings
The strings package is another standard library package that, as you might
imagine, deals with processing and manipulating strings. Unlike the fmt
package, which deals primarily with printing strings and placing variables in
them, strings provides functions to do all sorts of nifty stuff like converting
strings into uppercase or lowercase, building them piece-by-piece and also
splitting them up.
2.5.2 Using go doc To View Package Documentation
You can view the documentation for this package using another handy
command, go doc, which parses the source for documentation comments and
prints them out for you to read. By default, this command will print all
package functions and types, however you can use the -all flag to make it
print more detailed information, such as descriptions, methods or basic usage.
Listing 2.21. Using go doc To View The Documentation For Package strings
$ go doc -all strings
