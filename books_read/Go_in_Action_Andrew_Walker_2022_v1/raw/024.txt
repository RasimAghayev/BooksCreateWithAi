1.2 Summary
Go is a modern general-purpose language with powerful built-in
concurrency features.
Go is fast, and compiles quickly, leading to reduced development
overhead.
Go has a simple, easy-to-use type system with implicit interface
implementation and generic programming features.
Go is memory-safe and garbage collected, freeing the programmer from
both the tedium and the worry of manual memory management.
